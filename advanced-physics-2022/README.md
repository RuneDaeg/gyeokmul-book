## 보는 법

- `slides/index.html` 을 브라우저로 열면 됩니다. 수식(MathJax)과 글꼴은 인터넷에서 불러오므로 연결이 필요합니다.
- **발표 모드**: <kbd>P</kbd> 또는 오른쪽 위 버튼. <kbd>→</kbd>·<kbd>PageDown</kbd>·스페이스·화면 클릭으로 넘기고, <kbd>←</kbd>·<kbd>PageUp</kbd> 으로 돌아가며, <kbd>Esc</kbd> 로 끝냅니다.
- **한 줄씩 보기**: 발표 모드에서 유도 단계(번호 동그라미)와 번호 목록은 넘길 때마다 한 줄씩 나타납니다. 다 나온 뒤에 넘기면 다음 슬라이드로 가고, 이전 슬라이드로 돌아가면 모든 줄이 보입니다. <kbd>Shift</kbd>+<kbd>→</kbd> / <kbd>Shift</kbd>+<kbd>←</kbd> 는 단계를 건너뛰고 슬라이드 단위로 이동합니다. 아래 쪽에 '단계 3/6' 처럼 진행이 표시됩니다.
- **교사용 메모**: <kbd>N</kbd>. 슬라이드마다 2015 자료의 어떤 오류를 고쳤는지, 수업 운영 팁이 보입니다.
- **판서**: 오른쪽 위 '판서' 버튼이나 <kbd>D</kbd> (발표 모드에서는 오른쪽 아래 버튼). 펜 4색(<kbd>1</kbd>~<kbd>4</kbd>), 형광펜 <kbd>H</kbd>, 레이저 <kbd>L</kbd>, 지우개 <kbd>E</kbd>, 굵기 <kbd>W</kbd>, 되돌리기 <kbd>Z</kbd>, 이 쪽 지우기 <kbd>C</kbd>, 빈 화면 <kbd>B</kbd>, 끝내기 <kbd>Esc</kbd>.
  - 마우스·터치·스타일러스 펜 모두 됩니다. 펜은 누르는 세기에 따라 굵기가 바뀌고, 펜을 쓰는 동안에는 손바닥 터치를 무시합니다. 펜의 지우개 끝도 지우개로 동작합니다.
  - 판서는 그 브라우저에 쪽마다 저장됩니다 (슬라이드 제목 기준이라 원고를 고쳐 다시 빌드해도 제 쪽을 따라갑니다). 다른 컴퓨터로는 옮겨지지 않습니다.
  - 판서한 화면을 PDF로 남기려면 <kbd>Ctrl</kbd>+<kbd>P</kbd> → 'PDF로 저장'. 인쇄할 때는 풀이가 펼쳐지고, 한 쪽을 넘는 슬라이드는 글자를 줄여 맞춥니다.
- **유도·풀이 슬라이드**: 번호 붙은 단계로 식을 끌어내는 슬라이드(머리 표시 '유도'·'풀이'·'어림', 모두 93장)입니다. 교과서가 유도하는 식은 교과서의 순서와 기호를 따랐습니다.
- 확인 문제 풀이는 접혀 있습니다. 인쇄하면 펼쳐진 상태로 나옵니다.
- 밝은 화면과 어두운 화면을 모두 지원합니다 (시스템 설정을 따름).

## 고치는 법

슬라이드 원고는 `src/*.html`, 그림은 `tools/figures.py`(실제 식으로 계산한 SVG)에 있습니다. 고친 뒤 이 폴더에서

```bash
python3 tools/build.py
```

를 실행하면 `slides/` 가 다시 만들어집니다. 오류 목록 페이지(`slides/errors.html`)도 이때 `verification-report.md` 4장에서 새로 만들어집니다. 원고에서 `{{fig:이름}}` 자리에 그림이 들어가고, 쪽 번호와 머리말은 자동으로 붙습니다.

PDF는 Node.js와 Playwright로 다시 만듭니다 (처음 한 번 `npm install playwright` 와 `npx playwright install chromium`).

```bash
node tools/make_pdf.js
```

## 검증 범위

- 검증한 2015 자료: Notion 「2026 수업자료 모음」의 OT(화) 슬라이드 104쪽, OT 수학 유인물 29쪽, 역학 308쪽, 전자기학 357쪽, 양자역학 147쪽, 상대성 이론 101쪽. 모든 쪽을 이미지로 확인했고, 계산이 의심스러운 곳은 수치로 검산했습니다.
- 대조 기준: 「고등학교 고급 물리학」(2022 개정, 대전광역시교육감 인정 22-대전-31-고교-24-001, 조영원·윤달재·이나리) 본문 PDF 330쪽. 차례, 중단원 학습 계획, 소단원 학습 목표, 본문 주제어의 쪽 번호로 대조했습니다.
- 슬라이드마다 머리 표시에 교과서 쪽을 적었고, 교과서에 없는 내용은 '심화 · 교과서 밖'으로 표시했습니다.

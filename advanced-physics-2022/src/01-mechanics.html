I-1

힘과 운동

교과서 10~21쪽 · 벡터의 성분을 이용하여 지표면 근처의 포물선 운동을 분석한다 · 힘과 운동의 관계를 다루는 뉴턴 운동 법칙을 이해한다

운동의 기술

위치, 속도, 가속도 벡터

$$\vec r(t) = x\hat x + y\hat y + z\hat z,\qquad \vec v = \frac{d\vec r}{dt},\qquad \vec a = \frac{d\vec v}{dt}$$

거꾸로, 가속도를 알면 두 번 적분해서 위치를 얻습니다.

$$\vec v(t) = \vec v_0 + \int_0^t\vec a\,dt',\qquad \vec r(t) = \vec r_0 + \int_0^t\vec v\,dt'$$
원운동에서

반지름 $r$ 인 원 위를 각속도 $\omega$ 로 돌면 $v = r\omega$ 이고, 가속도는

$$a_t = r\alpha\ \ (\text{접선}),\qquad a_c = \frac{v^2}{r} = r\omega^2\ \ (\text{중심 방향})$$

등속 원운동에서도 속도의 방향이 바뀌므로 가속도는 0이 아닙니다.

포물선 운동 · 1

벡터 한 줄로 쓰는 포물선 운동

공기 저항이 없으면 가속도는 $\vec a = \vec g = -g\hat y$ 로 일정합니다.

$$\vec r(t) = \vec r_0 + \vec v_0t + \tfrac12\vec g\,t^2$$

성분으로 나누면 수평은 등속, 연직은 등가속도입니다.

$$x = v_0\cos\theta\,t,\qquad y = v_0\sin\theta\,t - \tfrac12gt^2$$
$$H = \frac{v_0^2\sin^2\theta}{2g},\qquad R = \frac{v_0^2\sin2\theta}{g}$$
예제

$v_0 = 20$ m/s, $\theta = 30^\circ$, $g = 9.8$ m/s²

풀이 보기

$v_x = 17.3$ m/s, $v_y = 10.0$ m/s

최고점 도달 $t = v_y/g = 1.02$ s, $H = 5.10$ m

비행 시간 $2.04$ s, $R = 35.3$ m

같은 $v_0$ 에서 $R$ 이 가장 큰 각은 $45^\circ$ 이고, $30^\circ$ 와 $60^\circ$ 의 $R$ 은 같습니다.

유도 · 포물선 운동 · 교과서 14~15쪽

가속도를 두 번 적분해 궤적과 도달 거리 구하기

  1. 공기 저항이 없으면 성분마다 가속도가 일정하다. 출발점을 원점, 위쪽을 $+y$ 로 잡는다.

    $$a_x = 0,\qquad a_y = -g$$

  2. 한 번 적분하고, 처음 속도 $(v_0\cos\theta,\ v_0\sin\theta)$ 로 적분 상수를 정한다.

    $$v_x = v_0\cos\theta,\qquad v_y = v_0\sin\theta - gt$$

  3. 한 번 더 적분한다.

    $$x = v_0\cos\theta\,t,\qquad y = v_0\sin\theta\,t - \tfrac12gt^2$$

  4. 첫 식의 $t = x/(v_0\cos\theta)$ 를 둘째 식에 넣어 $t$ 를 없애면 포물선이다.

    $$y = x\tan\theta - \frac{g}{2v_0^2\cos^2\theta}\,x^2$$

  5. 최고점에서는 $v_y = 0$ 이다.

    $$t_H = \frac{v_0\sin\theta}{g},\qquad H = v_0\sin\theta\,t_H - \tfrac12gt_H^2 = \frac{v_0^2\sin^2\theta}{2g}$$

  6. 다시 $y = 0$ 이 되는 시각은 $2t_H$ 이다. $2\sin\theta\cos\theta = \sin2\theta$ 를 쓴다.

    $$R = v_0\cos\theta\cdot\frac{2v_0\sin\theta}{g} = \frac{v_0^2\sin2\theta}{g}\ \le\ \frac{v_0^2}{g}\ \ (\theta = 45^\circ)$$

뉴턴 법칙

운동 방정식은 미분방정식이다

$$m\frac{d^2\vec r}{dt^2} = \sum\vec F\big(\vec r,\vec v,t\big)$$
  • 제1법칙: 알짜힘이 0이면 속도가 일정합니다. 이 법칙이 성립하는 기준계가 관성 좌표계입니다.
  • 제2법칙: $\vec F_{net} = d\vec p/dt$ 이고, 질량이 일정하면 $m\vec a$ 입니다.
  • 제3법칙: 두 물체가 서로에게 주는 힘은 크기가 같고 방향이 반대이며 같은 작용선 위에 있습니다. 두 힘은 서로 다른 물체에 작용합니다.
문제를 푸는 순서
  1. 물체 하나를 골라 자유 물체 도형을 그린다.
  2. 좌표축을 정하고 힘을 성분으로 나눈다.
  3. 성분마다 $m\ddot x = \sum F_x$ 를 세운다.
  4. 초기 조건으로 적분 상수를 정한다.

저항력 · 1

선형 저항 속 낙하: 종단 속도

느린 속도의 작은 물체는 속도에 비례하는 저항 $\vec F_D = -b\vec v$ 를 받습니다. 아래쪽을 $+$ 로 잡으면

$$m\frac{dv}{dt} = mg - bv$$

1계 선형 방정식이므로 $v(0) = 0$ 에서

$$v(t) = v_T\big(1 - e^{-t/\tau}\big),\qquad v_T = \frac{mg}{b},\ \ \tau = \frac mb$$

$t = \tau$ 에서 $v_T$ 의 63 %, $t = 3\tau$ 에서 95 %에 이릅니다.

유도 · 선형 저항 · 교과서 20쪽 식 (Ⅰ. 1-39~43)

변수 분리로 속도 v(t) 와 위치 y(t) 구하기

  1. 아래쪽을 $+$ 로 잡은 운동 방정식을 종단 속력 $v_t = mg/b$ 와 $\tau = m/b$ 로 정리한다.

    $$\frac{dv}{dt} = g - \frac bm v = \frac{v_t - v}{\tau}$$

  2. $v$ 가 든 항과 $t$ 가 든 항을 양변으로 나눈다 (변수 분리).

    $$\frac{dv}{v_t - v} = \frac{dt}{\tau}$$

  3. 처음 상태 $(t = 0,\ v = 0)$ 부터 $(t,\ v)$ 까지 양변을 적분한다.

    $$-\ln\frac{v_t - v}{v_t} = \frac t\tau$$

  4. 지수 함수로 풀면 교과서 식 (Ⅰ. 1-42)이다. $t\to\infty$ 이면 $v\to v_t$.

    $$v(t) = v_t\big(1 - e^{-t/\tau}\big)$$

  5. $y(0) = 0$ 으로 한 번 더 적분하면 위치다 (식 Ⅰ. 1-43).

    $$y(t) = v_t\,t - v_t\tau\big(1 - e^{-t/\tau}\big)$$

  6. 검산: $t \ll \tau$ 이면 $e^{-x}\approx 1 - x + \tfrac12x^2$ 이므로 자유 낙하로 돌아간다 ($v_t/\tau = g$).

    $$v \approx v_t\frac t\tau = gt,\qquad y \approx \frac{v_t}{2\tau}t^2 = \tfrac12gt^2$$

저항력 · 2

제곱형 저항과 포물선 궤적의 변화

빠른 물체(공, 사람)는 크기가 $cv^2$ 이고 운동 반대 방향인 저항을 받습니다.

$$\vec F_D = -c\,|\vec v|\,\vec v,\qquad c = \tfrac12 C_D\rho A$$

종단 속도는 $mg = cv_T^2$ 에서 $v_T = \sqrt{mg/c}$ 입니다.

예: 스카이다이버 $m = 80$ kg, $c \approx 0.25$ kg/m 이면 $v_T \approx 56$ m/s.

기존 역학 p26의 $F = -cv^2$ 는 방향이 사라진 표기였습니다. 벡터로 $-c|\vec v|\vec v$ 로 쓰면 성분 방정식이 결합되어 있다는 것도 보입니다.

유도 · 심화 · 교과서 밖 · 제곱형 저항

연직 낙하 속력을 부분분수 적분으로 구하기

  1. 아래쪽을 $+$ 로 잡고, 종단 속력 $v_T = \sqrt{mg/c}$ 로 묶는다.

    $$m\frac{dv}{dt} = mg - cv^2 = c\big(v_T^2 - v^2\big)$$

  2. 변수 분리.

    $$\frac{dv}{v_T^2 - v^2} = \frac cm\,dt$$

  3. 왼쪽을 부분분수로 쪼갠다.

    $$\frac{1}{v_T^2 - v^2} = \frac{1}{2v_T}\Big(\frac{1}{v_T - v} + \frac{1}{v_T + v}\Big)$$

  4. $v(0) = 0$ 부터 적분한다.

    $$\frac{1}{2v_T}\ln\frac{v_T + v}{v_T - v} = \frac cm\,t$$

  5. $cv_T/m = g/v_T$ 를 쓰고 $v$ 에 대해 푼다. $\tanh x = \dfrac{e^x - e^{-x}}{e^x + e^{-x}}$.

    $$v(t) = v_T\tanh\frac{gt}{v_T}$$

  6. 예: $v_T = 56$ m/s 인 스카이다이버가 종단 속력의 90 %에 이르는 시간.

    $$t = \frac{v_T}{g}\tanh^{-1}0.9 = \frac{56}{9.8}\times1.47 \approx 8.4\ \text{s}$$

탄성력과 단진동 · 교과서 19쪽

용수철 진자: 2계 미분방정식의 첫 예

탄성 한계 안에서 탄성력은 변형에 비례합니다 (훅의 법칙 $F = -kx$). 뉴턴 제2법칙에 넣으면

$$m\frac{d^2x}{dt^2} = -kx$$

두 번 미분했을 때 자기 자신에 $-k/m$ 을 곱한 꼴이 되는 함수는 사인·코사인입니다.

$$x(t) = A\cos(\omega t + \phi),\qquad \omega = \sqrt{\frac km},\qquad T = 2\pi\sqrt{\frac mk}$$

진폭 $A$ 와 초기 위상 $\phi$ 는 처음 위치와 속도로 정해집니다. 주기는 진폭과 무관합니다.

예제

$k = 200$ N/m 인 용수철에 0.50 kg 물체를 달아 0.10 m 당겼다 놓았다. 각진동수, 주기, 최대 속력은?

풀이 보기

$\omega = \sqrt{200/0.50} = 20$ rad/s, $T = 2\pi/20 = 0.31$ s

$v_{max} = A\omega = 2.0$ m/s. 에너지로 검산: $\tfrac12kA^2 = 1.0$ J $= \tfrac12mv_{max}^2$

같은 꼴의 방정식이 전자기학의 LC 회로에서 다시 나옵니다.

유도 · 단순 조화 운동 · 교과서 19~20쪽

해를 넣어 확인하고, 초기 조건과 에너지로 정리하기

  1. 해의 후보를 두 번 미분한다.

    $$x = A\cos(\omega t+\phi),\quad \dot x = -A\omega\sin(\omega t+\phi),\quad \ddot x = -\omega^2x$$

  2. 운동 방정식 $\ddot x = -(k/m)\,x$ 와 비교한다.

    $$\omega^2 = \frac km,\qquad T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac mk}$$

  3. $t = 0$ 의 위치 $x_0$ 와 속도 $v_0$ 로 진폭과 위상을 정한다.

    $$x_0 = A\cos\phi,\ \ v_0 = -A\omega\sin\phi\ \Rightarrow\ A = \sqrt{x_0^2 + (v_0/\omega)^2}$$

  4. 운동 에너지와 탄성 퍼텐셜 에너지를 따로 쓴다.

    $$K = \tfrac12mA^2\omega^2\sin^2(\omega t+\phi),\qquad U = \tfrac12kA^2\cos^2(\omega t+\phi)$$

  5. $m\omega^2 = k$ 이고 $\sin^2 + \cos^2 = 1$ 이므로 합이 시간에 무관하다.

    $$E = K + U = \tfrac12kA^2$$

  6. 연직 용수철: 평형 위치 $y_0 = mg/k$ 에서 잰 변위 $y'$ 로 쓰면 중력 항이 사라져 같은 단진동이 된다.

    $$m\ddot y = mg - ky\ \xrightarrow{\ y\,=\,y_0 + y'\ }\ m\ddot y' = -ky'$$

탐구 활동

컴퓨터로 운동 방정식 풀기 (오일러 방법)

해석적으로 풀기 어려운 제곱형 저항도 짧은 시간 간격 $\Delta t$ 로 나누면 풀 수 있습니다.

$$\vec a_n = \vec g - \frac cm|\vec v_n|\vec v_n$$
$$\vec v_{n+1} = \vec v_n + \vec a_n\Delta t,\qquad \vec r_{n+1} = \vec r_n + \vec v_n\Delta t$$
  1. 스프레드시트에 $t,\ x,\ y,\ v_x,\ v_y$ 열을 만든다.
  2. $\Delta t = 0.01$ s 로 위 식을 아래로 채운다.
  3. $c = 0$ 일 때 해석해 $R = v_0^2\sin2\theta/g$ 와 비교해 방법을 검증한다.
  4. $c$ 를 바꾸며 최대 도달 거리를 주는 각이 $45^\circ$ 보다 작아지는지 확인한다.
생각해 볼 질문

$\Delta t$ 를 절반으로 줄이면 결과가 얼마나 달라지는가? 그 차이가 수치 해의 오차를 어림하는 방법이 됩니다.

I-2

일과 에너지

교과서 24~33쪽 · 일-운동 에너지 정리를 이해한다 · 보존력을 이해하고 역학적 에너지 보존 법칙을 설명할 수 있다

일-에너지 정리

알짜힘이 한 일 = 운동 에너지 변화

$$W_{net} = \int\vec F_{net}\cdot d\vec r = \int m\frac{d\vec v}{dt}\cdot\vec v\,dt = \Delta\Big(\tfrac12mv^2\Big)$$

여기서 일을 계산하는 힘은 알짜힘입니다. 힘 하나가 한 일만으로는 $\Delta K$ 가 정해지지 않습니다.

오개념 바로잡기

"물체를 천천히 들어 올리면 계의 에너지가 일정하다"는 틀렸습니다.

손(외력)이 $mgh$ 의 일을 하므로, 물체와 지구로 이루어진 계의 에너지는 $mgh$ 만큼 증가합니다. 이 에너지가 중력 퍼텐셜 에너지로 저장됩니다.

기존 역학 p40·p52 수정 사항: 계의 에너지 변화는 외력의 일과 같고, 일-에너지 정리의 힘은 알짜힘입니다.

유도 · 일-운동 에너지 정리 · 교과서 25~27쪽

뉴턴 제2법칙을 경로를 따라 적분하기

  1. 알짜힘이 짧은 변위 $d\vec r$ 동안 한 일.

    $$dW = \vec F_{net}\cdot d\vec r$$

  2. 제2법칙 $\vec F_{net} = m\,d\vec v/dt$ 와 $d\vec r = \vec v\,dt$ 를 넣는다.

    $$dW = m\frac{d\vec v}{dt}\cdot\vec v\,dt$$

  3. $v^2 = \vec v\cdot\vec v$ 를 미분하면 $2\,\vec v\cdot d\vec v/dt$ 이다.

    $$\frac{d\vec v}{dt}\cdot\vec v = \frac12\frac{d(v^2)}{dt}\ \Rightarrow\ dW = \tfrac12m\,d(v^2)$$

  4. 처음부터 끝까지 더한다. 힘이 변해도, 경로가 굽어도 성립한다.

    $$W_{net} = \int_{v_i}^{v_f}\tfrac12m\,d(v^2) = \tfrac12mv_f^2 - \tfrac12mv_i^2$$

  5. 예: 용수철($k$)이 $x = A$ 에서 $x = 0$ 까지 물체를 밀며 한 일.

    $$W = \int_A^0(-kx)\,dx = \tfrac12kA^2 = \tfrac12mv^2\ \Rightarrow\ v = A\sqrt{k/m}$$

  6. 힘이 속도에 늘 수직이면(등속 원운동의 구심력, 자기력) $dW = 0$ 이라 속력이 변하지 않는다.

    $$\vec F\perp\vec v\ \Rightarrow\ \vec F\cdot\vec v = 0\ \Rightarrow\ \Delta K = 0$$

보존력

경로에 무관한 일, 퍼텐셜 에너지

한 일이 경로와 무관하고 처음과 끝 위치로만 정해지는 힘이 보존력입니다.

$$\oint\vec F\cdot d\vec l = 0,\qquad \vec F = -\nabla U$$
$$U(B) - U(A) = -\int_A^B\vec F\cdot d\vec l$$
중력 (지표 근처)$U = mgy$
탄성력$U = \tfrac12kx^2$
만유인력$U = -GMm/r$
비보존력과 에너지 보존

마찰 같은 비보존력이 일을 하면 역학적 에너지 $K+U$ 가 보존되지 않습니다. 그 에너지는 열·소리·변형으로 바뀔 뿐 총에너지는 항상 보존됩니다.

자기력 $q\vec v\times\vec B$ 는 속도에 수직이라 일을 하지 않습니다. 보존력·비보존력과 따로 기억하세요.

기존 역학 p41·p43·p44에서 '비보존력이면 (질량-)에너지 보존이 성립하지 않는다', '강력·약력은 역학적 에너지 보존이 성립하지 않는다'는 서술을 바로잡았습니다.

유도 · 퍼텐셜 에너지 · 교과서 30~31쪽

힘을 적분해 퍼텐셜 에너지 구하기

  1. 정의: 퍼텐셜 에너지의 변화는 보존력이 한 일의 음수다.

    $$U(B) - U(A) = -\int_A^B\vec F\cdot d\vec l$$

  2. 지표 근처 중력 $\vec F = -mg\,\hat y$, 기준 $y = 0$.

    $$U(y) = -\int_0^y(-mg)\,dy' = mgy$$

  3. 탄성력 $F = -kx$, 기준은 자연 길이 $x = 0$.

    $$U(x) = -\int_0^x(-kx')\,dx' = \tfrac12kx^2$$

  4. 만유인력, 기준을 무한히 먼 곳($U = 0$)으로 잡는다.

    $$U(r) = -\int_\infty^r\Big(-\frac{GMm}{r'^2}\Big)dr' = \Big[-\frac{GMm}{r'}\Big]_\infty^r = -\frac{GMm}{r}$$

  5. 거꾸로 미분하면 힘이 돌아온다.

    $$F_r = -\frac{dU}{dr} = -\frac{GMm}{r^2}\ \ (\text{인력})$$

  6. 지표에서 $h$ 만큼 올릴 때 ($h \ll R$) 앞의 $mgh$ 와 같아진다.

    $$U(R+h) - U(R) = \frac{GMm\,h}{R(R+h)} \approx \frac{GM}{R^2}\,mh = mgh$$

퍼텐셜 에너지 곡선

E ≥ U 인 곳에서만 움직일 수 있다

$$K = E - U(x) \ge 0$$
  • $E$ 선이 $U$ 곡선보다 위에 있는 구간에서만 운동합니다.
  • $E = U$ 인 점은 전환점입니다. 순간 정지 후 되돌아옵니다.
  • $dU/dx = 0$ 이면 평형점입니다. $d^2U/dx^2 \gt 0$ (골짜기)이면 안정, $\lt0$ (봉우리)이면 불안정 평형입니다.
  • 양쪽 장벽보다 $E$ 가 낮으면 입자는 골짜기에 속박됩니다.
기존 역학 p50은 "역학적 에너지가 퍼텐셜 곡선보다 아래에 있으면 자유롭게 운동"이라고 반대로 서술했습니다.

입자계의 운동

교과서 38~48쪽 · 질량 중심을 이용하여 물체의 운동을 설명할 수 있다 · 운동량 보존 법칙을 이용하여 다양한 충돌 현상을 설명할 수 있다

운동량

충격량과 계의 운동량 보존

$$\vec J = \int\vec F\,dt = \Delta\vec p,\qquad \frac{d\vec P_{계}}{dt} = \sum\vec F_{외}$$

내력은 제3법칙에 따라 쌍으로 상쇄되므로 계의 운동량을 바꾸는 것은 외력뿐입니다.

충돌은 시간이 매우 짧고 내력이 매우 큽니다. 그동안 중력·마찰 같은 외력의 충격량 $\int\vec F_{외}dt$ 는 무시할 수 있어 운동량이 (근사적으로) 보존됩니다.

질량 중심
$$\vec R_{cm} = \frac{\sum m_i\vec r_i}{M},\qquad M\vec a_{cm} = \sum\vec F_{외}$$

외력이 없으면 질량 중심은 등속 운동합니다. 폭발 뒤 파편이 흩어져도 질량 중심은 원래 포물선을 그대로 따라갑니다.

유도 · 연속체의 질량 중심 · 교과서 40~41쪽 · 참고 Halliday 9-1, Boas 5.3~5.4

합을 적분으로: 막대, 반원 고리, 반원판의 질량 중심

  1. 질량이 연속적으로 퍼져 있으면 질점의 합을 작은 질량 요소 $dm$ 의 적분으로 바꾼다.

    $$\vec r_{cm} = \frac1M\sum m_i\vec r_i\ \to\ \frac1M\int\vec r\,dm$$

  2. 길이 $L$ 인 막대, 선밀도 $\lambda = \lambda_0x/L$ (끝으로 갈수록 무거움). $dm = \lambda\,dx$.

    $$x_{cm} = \frac{\int_0^Lx\,\lambda_0\frac xL\,dx}{\int_0^L\lambda_0\frac xL\,dx} = \frac{\lambda_0L^2/3}{\lambda_0L/2} = \frac23L$$

  3. 반지름 $R$ 인 반원 고리: 각 $\theta$ 에서 $d\theta$ 만큼의 호, $dm = \lambda R\,d\theta$, $y = R\sin\theta$.

    $$y_{cm} = \frac{1}{\lambda\pi R}\int_0^\pi R\sin\theta\,\lambda R\,d\theta = \frac{2R}{\pi} = 0.64R$$

  4. 반원판: 극좌표의 넓이 요소는 $dA = r\,dr\,d\theta$ (야코비안 $r$ 을 빠뜨리지 않는다).

    $$y_{cm} = \frac{1}{\pi R^2/2}\int_0^\pi\!\!\int_0^Rr\sin\theta\;r\,dr\,d\theta = \frac{2}{\pi R^2}\cdot\frac{R^3}{3}\cdot2 = \frac{4R}{3\pi}$$

  5. 비교: 질량이 바깥 테두리에 몰린 고리($0.64R$)가 속이 찬 판($0.42R$)보다 질량 중심이 멀다. 질량 중심은 물체 밖에 있을 수도 있다 (고리).

    $$\frac{4}{3\pi} = 0.42 \lt \frac2\pi = 0.64$$

유도 · 질량 중심의 운동 · 교과서 39~43쪽

내력은 쌍으로 지워지고 외력만 남는다

  1. 질량 중심 위치 $\vec R_{cm} = \sum m_i\vec r_i/M$ 를 시간으로 미분한다.

    $$M\vec V_{cm} = \sum m_i\vec v_i = \vec P$$

  2. 입자 $i$ 가 받는 힘은 외력과, 다른 입자 $j$ 가 주는 내력의 합이다.

    $$\frac{d\vec p_i}{dt} = \vec F_i^{\,외} + \sum_{j\ne i}\vec F_{ij}$$

  3. 모든 입자에 대해 더한다.

    $$\frac{d\vec P}{dt} = \sum_i\vec F_i^{\,외} + \sum_i\sum_{j\ne i}\vec F_{ij}$$

  4. 제3법칙 $\vec F_{ij} = -\vec F_{ji}$: 내력은 쌍으로 묶으면 0이다.

    $$\sum_i\sum_{j\ne i}\vec F_{ij} = \sum_{i\lt j}\big(\vec F_{ij} + \vec F_{ji}\big) = 0$$

  5. 결과: 질량 중심은 외력만 받는 질점처럼 움직인다.

    $$M\vec a_{cm} = \sum\vec F^{\,외},\qquad \sum\vec F^{\,외} = 0\ \Rightarrow\ \vec P = \text{일정}$$

  6. 예: 매끄러운 빙판 위에 정지한 60 kg 학생이 3.0 kg 공을 6.0 m/s 로 던지면

    $$0 = (3.0)(6.0) + (60)\,v\ \Rightarrow\ v = -0.30\ \text{m/s}$$

유도 · 로켓 방정식 · 교과서 43쪽 심화 탐구 · 참고 Halliday 9-9

질량이 줄어드는 로켓의 속력 구하기

  1. 외력이 없다고 하자. 시각 $t$ 에 로켓(연료 포함)의 질량 $M$, 속도 $v$. 짧은 시간 $dt$ 동안 질량 $-dM$ $(\gt0)$ 의 가스를 로켓에 대해 속력 $u$ 로 뒤로 뿜는다.

    $$\text{가스의 속도(지면 기준)} = (v + dv) - u$$

  2. 로켓과 가스로 이루어진 계의 운동량이 보존된다.

    $$Mv = (M + dM)(v + dv) + (-dM)(v + dv - u)$$

  3. 정리하면 (아주 작은 양의 곱 $dM\,dv$ 는 지워진다)

    $$M\,dv = -u\,dM$$

  4. $dt$ 로 나누면 추력. $R = -dM/dt$ 는 연료를 태우는 빠르기다 (제1 로켓 방정식).

    $$Ma = Ru\qquad(\text{추력 } Ru)$$

  5. 3단계를 변수 분리해 처음 질량 $M_i$ 부터 나중 질량 $M_f$ 까지 적분한다 (제2 로켓 방정식).

    $$\int_{v_i}^{v_f}dv = -u\int_{M_i}^{M_f}\frac{dM}{M}\ \Rightarrow\ v_f - v_i = u\ln\frac{M_i}{M_f}$$

  6. 예: $u = 2.5$ km/s, 질량비 $M_i/M_f = 5$ 이면 $\Delta v = 4.0$ km/s 로, 지표 원 궤도 속력 7.9 km/s 에 모자란다. 그래서 다 쓴 연료통을 버리는 다단 로켓을 쓴다.

    $$\Delta v = 2.5\ln5 = 4.0\ \text{km/s}$$

1차원 충돌

반발 계수와 운동 에너지 손실 Q

$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$
$$e = -\frac{v_1'-v_2'}{v_1-v_2}$$

탄성 충돌($e = 1$)의 결과 (유도는 다음 슬라이드):

$$v_1' = \frac{(m_1-m_2)v_1 + 2m_2v_2}{m_1+m_2}$$
$$v_2' = \frac{2m_1v_1 + (m_2-m_1)v_2}{m_1+m_2}$$
Q의 정의와 부호
$$K_i = K_f + Q,\qquad \mu = \frac{m_1m_2}{m_1+m_2}$$
$$Q = \tfrac12\mu\,(1-e^2)\,(v_1-v_2)^2$$
  • $Q = 0$: 탄성 충돌 ($e=1$)
  • $Q \gt 0$: 비탄성 충돌. 운동 에너지가 열·소리·변형으로 감 ($e=0$ 이면 완전 비탄성)
  • $Q \lt 0$: 운동 에너지 증가 (화학·용수철 에너지가 풀리는 폭발)
기존 역학 p65는 같은 식 K_i = K_f + Q 를 쓰면서 Q의 부호를 반대로 설명했습니다. 핵반응 관례(Q = K_f − K_i)를 쓰려면 식을 K_i + Q = K_f 로 바꿔야 합니다.

유도 · 1차원 충돌 · 교과서 44~46쪽

탄성 충돌의 결과 식과 Q 식 만들기

  1. 운동량 보존을 질량별로 모은다.

    $$m_1(v_1 - v_1') = m_2(v_2' - v_2)$$

  2. 탄성 충돌이면 운동 에너지 보존도 같은 꼴로 인수분해된다.

    $$m_1(v_1 - v_1')(v_1 + v_1') = m_2(v_2' - v_2)(v_2' + v_2)$$

  3. 2단계 식을 1단계 식으로 나눈다: 상대 속도는 크기가 같고 방향만 반대 ($e = 1$).

    $$v_1 + v_1' = v_2 + v_2'\ \Leftrightarrow\ v_1' - v_2' = -(v_1 - v_2)$$

  4. $v_2' = v_1 + v_1' - v_2$ 를 1단계 식에 넣어 정리한다.

    $$v_1' = \frac{(m_1 - m_2)\,v_1 + 2m_2\,v_2}{m_1 + m_2}$$

  5. 운동 에너지를 질량 중심 부분과 상대 운동 부분으로 나눌 수 있다.

    $$K = \tfrac12MV_{cm}^2 + \tfrac12\mu\,(v_1 - v_2)^2,\qquad \mu = \frac{m_1m_2}{m_1 + m_2}$$

  6. $V_{cm}$ 은 충돌 전후 같고, 상대 속도는 $-e$ 배가 되므로

    $$Q = K_i - K_f = \tfrac12\mu\,(1 - e^2)(v_1 - v_2)^2$$

특수한 경우: $m_1 = m_2$ 이면 두 물체가 속도를 맞바꾸고, $m_2 \gg m_1$ 이면 $v_1' \approx -v_1 + 2v_2$ (벽에 튕기기).

2차원 충돌 · 실험실 좌표계

성분마다 운동량 보존

정지한 $m_2$ 에 $m_1$ 이 $v_1$ 로 부딪혀 각각 $\theta_1$, $\theta_2$ 방향으로 흩어지면

$$\begin{aligned} x:&\ \ m_1v_1 = m_1v_1'\cos\theta_1 + m_2v_2'\cos\theta_2\\ y:&\ \ 0 = m_1v_1'\sin\theta_1 - m_2v_2'\sin\theta_2\end{aligned}$$

탄성 충돌이면 $\tfrac12m_1v_1^2 = \tfrac12m_1v_1'^2 + \tfrac12m_2v_2'^2$ 이 더해집니다.

같은 질량의 탄성 충돌

$m_1 = m_2$ 이면 $\vec v_1 = \vec v_1' + \vec v_2'$ 이고 $v_1^2 = v_1'^2 + v_2'^2$ 입니다.

첫 식을 제곱하면 $v_1^2 = v_1'^2 + v_2'^2 + 2\vec v_1'\cdot\vec v_2'$ 이므로

$$\vec v_1'\cdot\vec v_2' = 0\ \Rightarrow\ \theta_1 + \theta_2 = 90^\circ$$

당구공이 맞은 뒤 두 공이 직각으로 흩어지는 이유입니다 (회전 효과 무시).

풀이 · 2차원 충돌 · 교과서 47쪽

당구공의 비스듬한 충돌을 성분으로 풀기

같은 질량의 공 A가 2.0 m/s 로 정지한 공 B에 비스듬히 부딪쳐, A가 처음 방향에서 $30^\circ$ 꺾여 나갔다. 탄성 충돌일 때 두 공의 나중 속력과 B의 방향은?

  1. 같은 질량의 탄성 충돌이면 두 공은 직각으로 흩어진다 (앞 슬라이드).

    $$\theta_B = 90^\circ - 30^\circ = 60^\circ\ \ (\text{처음 방향의 반대쪽})$$

  2. $x$ 성분 운동량 보존.

    $$2.0 = v_A'\cos30^\circ + v_B'\cos60^\circ$$

  3. $y$ 성분 운동량 보존에서 $v_B'$ 를 $v_A'$ 로 쓴다.

    $$0 = v_A'\sin30^\circ - v_B'\sin60^\circ\ \Rightarrow\ v_B' = 0.577\,v_A'$$

  4. 2단계 식에 넣어 푼다.

    $$2.0 = v_A'(0.866 + 0.289)\ \Rightarrow\ v_A' = 1.73\ \text{m/s},\ \ v_B' = 1.00\ \text{m/s}$$

  5. 검산: 운동 에너지가 보존되는가?

    $$v_A'^2 + v_B'^2 = 3.0 + 1.0 = 4.0 = (2.0)^2\ \ \checkmark$$

심화 · 교과서 밖 · 질량 중심 좌표계

질량 중심과 함께 움직이며 보면 단순해진다

질량 중심 속도 $\vec V_{cm} = \dfrac{m_1\vec v_1 + m_2\vec v_2}{m_1+m_2}$ 로 움직이는 좌표계에서는 계의 운동량이 0입니다.

$$\vec u_i = \vec v_i - \vec V_{cm},\qquad m_1\vec u_1 + m_2\vec u_2 = 0$$
  • 두 입자는 항상 정반대 방향으로 움직입니다.
  • 탄성 충돌이면 각 입자의 속력은 그대로이고 방향만 같은 각만큼 돕니다.
  • 실험실 속도는 다시 $\vec v_i' = \vec u_i' + \vec V_{cm}$ 로 돌아옵니다.
왜 쓰는가

충돌로 '쓸 수 있는' 운동 에너지는 질량 중심 좌표계의 운동 에너지 $\tfrac12\mu v_{rel}^2$ 뿐입니다. $\tfrac12MV_{cm}^2$ 는 운동량 보존 때문에 충돌 뒤에도 남아야 합니다.

완전 비탄성 충돌의 손실 $Q = \tfrac12\mu v_{rel}^2$ 가 바로 이 값입니다.

탐구 활동 · 수행평가 연계

2차원 충돌 실험 보고서

  1. 에어 테이블 또는 매끄러운 책상 위에서 두 퍽(또는 동전)을 충돌시키고 위에서 촬영한다.
  2. Tracker로 충돌 전후 각 물체의 $v_x,\ v_y$ 를 구한다. 자로 길이 눈금을 맞춘다.
  3. $x,\ y$ 성분의 총운동량을 충돌 전후로 비교한다.
  4. 운동 에너지 비 $K_f/K_i$ 와 산란각 합 $\theta_1+\theta_2$ 를 구한다.

Q1

질량 2 kg, 속도 3 m/s 인 수레가 정지한 1 kg 수레와 부딪혀 한 덩어리가 되었다. 충돌 뒤 속도와 $Q$ 를 구하시오.

Q2

$U(x) = x^3 - 3x$ (J, $x$ 는 m)일 때 평형점과 그 안정성을 판단하시오. 역학적 에너지가 1 J인 입자가 $x = 0$ 에 있다면 운동 가능한 구간은?

풀이 보기

$U' = 3x^2 - 3 = 0$ 에서 $x = \pm1$. $U'' = 6x$ 이므로 $x = 1$ 은 안정, $x = -1$ 은 불안정 평형.

회전의 기술

각위치, 각속도, 각가속도

$$\omega = \frac{d\theta}{dt},\qquad \alpha = \frac{d\omega}{dt}$$

각속도는 단위 시간당 각위치의 변화, 각가속도는 단위 시간당 각속도의 변화입니다.

반지름 $r$ 인 점이 움직인 호의 길이는 $s = r\theta$ 이므로

$$v = \frac{ds}{dt} = r\omega,\qquad a_t = r\alpha,\qquad a_c = r\omega^2$$
직선 운동고정축 회전
$x,\ v,\ a$$\theta,\ \omega,\ \alpha$
질량 $m$회전 관성 $I$
힘 $F = ma$돌림힘 $\tau = I\alpha$
운동량 $p = mv$각운동량 $L = I\omega$
$K = \tfrac12mv^2$$K = \tfrac12I\omega^2$
$W = \int F\,dx$$W = \int\tau\,d\theta$
기존 역학 p94는 각속도를 '각속도의 변화'로, p95는 $v = dr/dt = r\omega$ 로 썼습니다. 반지름이 일정하면 $dr/dt = 0$ 이므로 호의 길이 $s$ 로 써야 합니다.

회전 관성 · 교과서 55~56쪽

회전 관성(관성 모멘트): 질량이 축에서 얼마나 멀리 있는가

$$K = \sum\tfrac12m_iv_i^2 = \tfrac12\Big(\sum m_ir_i^2\Big)\omega^2,\qquad I = \int r^2\,dm$$
물체 (질량 M)회전축I
가는 막대 (길이 L)중심$\tfrac1{12}ML^2$

고리 (반지름 R)중심축$MR^2$
원판·원기둥중심축$\tfrac12MR^2$

유도 · 회전 관성 · 교과서 55~56쪽

적분으로 구하는 회전 관성: 고리, 원판, 구

  1. 고리: 모든 질량이 축에서 같은 거리 $R$ 에 있다.

    $$I = \int R^2\,dm = MR^2$$

  2. 원판: 폭 $dr$ 인 고리로 쪼갠다. 면밀도 $\sigma = M/\pi R^2$.

    $$I = \int_0^R r^2\,\sigma\,2\pi r\,dr = \frac{\pi\sigma R^4}{2} = \tfrac12MR^2$$

  3. 속이 찬 구: 높이 $z$, 두께 $dz$ 인 얇은 원판(반지름² $= R^2 - z^2$)으로 쪼개고 2단계 결과를 쓴다.

    $$dm = \rho\,\pi(R^2 - z^2)\,dz,\qquad dI = \tfrac12\,dm\,(R^2 - z^2)$$

  4. $z = -R$ 부터 $R$ 까지 더한다.

    $$I = \frac{\pi\rho}{2}\int_{-R}^{R}(R^2 - z^2)^2\,dz = \frac{\pi\rho}{2}\cdot\frac{16R^5}{15}$$

  5. 밀도 $\rho = 3M/(4\pi R^3)$ 를 넣는다.

    $$I = \frac{8\pi R^5}{15}\cdot\frac{3M}{4\pi R^3} = \tfrac25MR^2$$

같은 질량·반지름이면 고리 > 원판 > 구 순서입니다. 질량이 축에서 멀리 있을수록 회전 관성이 큽니다.

평행축 정리와 수직축 정리

평행축 정리 · 모든 물체
$$I = I_{cm} + Md^2$$

질량 중심을 지나는 축과 거리 $d$ 만큼 떨어진 평행한 축. 예: 막대 끝 $\tfrac1{12}ML^2 + M(L/2)^2 = \tfrac13ML^2$

수직축 정리 · 얇은 판에서만
$$I_z = I_x + I_y\qquad(\text{판이 } xy \text{ 평면에 놓인 경우})$$

$I_x = \int(y^2+z^2)dm$ 이고 판에서는 $z = 0$ 이라서 성립합니다. 두께가 있는 물체에서는

$$I_x + I_y = I_z + 2\int z^2\,dm$$

예: 원판 $I_z = \tfrac12MR^2$ 이면 지름축 $I_x = \tfrac14MR^2$

기존 역학 p106은 수직축 정리를 '서로 수직한 세 회전축'의 일반 관계로 제시해 얇은 판 조건이 빠져 있었습니다.

유도 · 평행축 정리 · 교과서 56쪽

질량 중심의 정의가 가운데 항을 지운다

질량 중심을 지나는 축에서 잰 질점 $i$ 의 위치(축에 수직인 성분)를 $\vec\rho_i$, 새 축의 위치를 $\vec d$ 라 하자.

  1. 새 축까지 거리의 제곱을 전개한다.

    $$|\vec\rho_i - \vec d|^2 = \rho_i^2 - 2\,\vec\rho_i\cdot\vec d + d^2$$

  2. 질량을 곱해 모두 더한다.

    $$I = \sum m_i\rho_i^2 - 2\,\vec d\cdot\sum m_i\vec\rho_i + Md^2$$

  3. 질량 중심에서 잰 위치의 질량 가중 합은 0이다.

    $$\sum m_i\vec\rho_i = M\vec\rho_{cm} = 0$$

  4. 결과.

    $$I = I_{cm} + Md^2$$

  5. 예: 원판 가장자리를 지나고 판에 수직인 축.

    $$I = \tfrac12MR^2 + MR^2 = \tfrac32MR^2$$

$Md^2 \ge 0$ 이므로 같은 방향의 축 가운데 질량 중심을 지나는 축의 회전 관성이 가장 작습니다.

돌림힘과 각운동량

정의와, 거기서 나오는 법칙

정의

$$\vec\tau = \vec r\times\vec F,\qquad \vec L = \vec r\times\vec p$$

법칙 (뉴턴 제2법칙에서 유도)

$$\frac{d\vec L}{dt} = \vec v\times m\vec v + \vec r\times\vec F = \vec\tau$$

계 전체로는 내부 돌림힘이 상쇄되어 $d\vec L_{계}/dt = \vec\tau_{외}$ 입니다.

성립 조건

$L = I\omega$, $\tau = I\alpha$ 는 고정축(또는 대칭축) 둘레 회전에서 그 축 성분으로만 성립합니다. 일반적인 3차원 회전에서 $\vec L$ 과 $\vec\omega$ 는 방향이 다를 수 있습니다.

기존 역학 p97·98·110·117은 $\vec L = I\vec\omega$, $\vec\tau = I\vec\alpha$ 를 정의처럼 썼습니다.

유도 · 고정축 회전 · 교과서 57~58쪽

질점 하나씩 더해 τ = Iα, L = Iω 얻기

  1. 축에서 $r_i$ 떨어진 질점의 접선 방향 운동 방정식 ($a_t = r\alpha$).

    $$F_{t,i} = m_ia_{t,i} = m_ir_i\,\alpha$$

  2. 양변에 $r_i$ 를 곱하면 돌림힘이 된다.

    $$\tau_i = r_iF_{t,i} = m_ir_i^2\,\alpha$$

  3. 모두 더한다. 내력의 돌림힘은 쌍으로 상쇄된다.

    $$\tau_{외} = \Big(\sum m_ir_i^2\Big)\alpha = I\alpha$$

  4. 축 방향 각운동량도 같은 방법으로 ($v_i = r_i\omega$).

    $$L_z = \sum r_i\,(m_iv_i) = \Big(\sum m_ir_i^2\Big)\omega = I\omega$$

  5. 돌림힘이 한 일: 호의 길이 $ds = r\,d\theta$.

    $$dW = F_t\,ds = F_t\,r\,d\theta = \tau\,d\theta$$

  6. 회전의 일-에너지 정리 ($\alpha\,d\theta = \omega\,d\omega$).

    $$W = \int\tau\,d\theta = \int I\omega\,d\omega = \tfrac12I\omega_f^2 - \tfrac12I\omega_i^2$$

각운동량 보존

외부 돌림힘이 없으면 L은 일정하다

$$\vec\tau_{외} = 0\ \Rightarrow\ I_i\omega_i = I_f\omega_f$$
피겨 스케이터

팔을 당겨 $I$ 가 $\tfrac13$ 로 줄면 $\omega$ 는 3배가 됩니다.

운동 에너지 $K = \dfrac{L^2}{2I}$ 는 3배로 늘어납니다. 늘어난 에너지는 팔을 안쪽으로 당기는 근육이 한 일입니다.

  • 회전 의자 위에서 아령을 당기거나 펴기
  • 다이버의 공중회전: 몸을 웅크리면 빨리 돈다
  • 중성자별: 붕괴하며 반지름이 줄어 초당 수백 번 회전
  • 행성 궤도: 중심력은 돌림힘이 없어 면적 속도가 일정 (케플러 제2법칙)

심화 · 교과서 밖 · 정성적으로

세차 운동: 각운동량의 방향이 돈다

빠르게 도는 팽이에 중력이 만드는 돌림힘 $\vec\tau = \vec r\times M\vec g$ 는 $\vec L$ 에 수직입니다. 그래서 $\vec L$ 의 크기는 그대로이고 방향만 수평으로 돕니다.

$$\Omega = \frac{d\phi}{dt} = \frac{\tau}{L} = \frac{Mgr}{I\omega}$$

돌림힘이 있으므로 이때 각운동량은 보존되지 않습니다.

오개념 바로잡기 · 자전거

"자전거가 넘어지지 않는 것은 바퀴의 각운동량이 보존되기 때문"은 틀린 설명입니다.

달리는 자전거의 안정성은 주로 앞바퀴의 조향 기하(트레일)와 질량 분포, 그리고 타는 사람의 조향에서 옵니다. 바퀴의 자이로 효과는 부차적입니다. 자이로 효과를 없앤 실험용 자전거도 스스로 균형을 잡습니다 (Kooijman 외, Science 2011).

행성의 운동 · 교과서 60~62쪽

케플러 법칙은 뉴턴 역학의 결과다

  1. 제1법칙 (타원 궤도): 행성은 태양을 한 초점으로 하는 타원 궤도를 돈다. 역제곱 중심력을 받는 물체의 궤도는 원뿔 곡선이고, 역학적 에너지가 음수이면 닫힌 궤도인 타원이 된다.
  2. 제2법칙 (면적 속도 일정): 중력은 중심력이라 돌림힘이 0이고 각운동량이 보존된다.
  3. 제3법칙 (조화 법칙): $T^2 \propto a^3$, 비례 상수는 행성의 질량과 무관하다.
유도의 핵심
$$\frac{dA}{dt} = \frac12|\vec r\times\vec v| = \frac{L}{2m} = \text{일정}$$

근일점과 원일점에서 역학적 에너지 보존과 각운동량 보존을 함께 쓰면 (교과서 62~63쪽)

$$T^2 = \frac{4\pi^2}{GM}a^3$$

예: 지구 궤도 $a = 1.496\times10^{11}$ m, $T = 1$ 년을 넣으면 태양 질량 $M = 1.99\times10^{30}$ kg 이 나옵니다.

유도 · 케플러 제2·3법칙 · 교과서 59~62쪽

면적 속도 일정과 조화 법칙 끌어내기

  1. 짧은 시간 $dt$ 동안 태양-행성 선분이 휩쓴 삼각형의 넓이.

    $$dA = \tfrac12\,|\vec r\times\vec v\,dt|$$

  2. 각운동량 $L = m|\vec r\times\vec v|$ 로 쓴다.

    $$\frac{dA}{dt} = \frac{L}{2m}$$

  3. 중력은 $\vec r$ 방향(중심력)이라 돌림힘이 0이다. 그래서 면적 속도가 일정하다 (제2법칙).

    $$\vec\tau = \vec r\times\vec F = 0\ \Rightarrow\ L = \text{일정}$$

  4. 원 궤도(반지름 $r$)에서 중력이 구심력 역할을 한다.

    $$\frac{GMm}{r^2} = \frac{mv^2}{r},\qquad v = \frac{2\pi r}{T}$$

  5. $v$ 를 없앤다 (제3법칙). 타원 궤도에서는 $r$ 이 긴반지름 $a$ 로 바뀐다.

    $$T^2 = \frac{4\pi^2}{GM}\,r^3$$

  6. 예: 지구 공전 ($a = 1.496\times10^{11}$ m, $T = 3.156\times10^7$ s)으로 태양 질량을 잰다.

    $$M = \frac{4\pi^2a^3}{GT^2} = \frac{4\pi^2(1.496\times10^{11})^3}{(6.674\times10^{-11})(3.156\times10^{7})^2} = 1.99\times10^{30}\ \text{kg}$$

인공위성 · 교과서 63~65쪽

원 궤도의 속력과 정지 궤도

지구 중력이 구심력 역할을 하므로

$$\frac{GMm}{r^2} = \frac{mv^2}{r}\ \Rightarrow\ v = \sqrt{\frac{GM}{r}}$$

위성의 질량과 무관합니다. 국제 우주 정거장(고도 약 400 km)은 $v \approx 7.67$ km/s, 주기 약 92분입니다.

뉴턴의 대포 사고 실험: 수평으로 쏘는 속력을 키우면 떨어지는 지점이 멀어지다 결국 지구를 한 바퀴 도는 궤도가 됩니다.

정지 궤도 위성

주기가 지구 자전 주기(항성일) $T = 86\,164$ s 와 같아야 하므로

$$r = \Big(\frac{GM_ET^2}{4\pi^2}\Big)^{1/3} = 4.216\times10^7\ \text{m}$$

고도 약 35 800 km, 속력 $2\pi r/T \approx 3.07$ km/s, 적도면 위. 통신·기상 위성이 여기에 있습니다.

기존 역학 p167은 태양일 86 400 s로 계산해 반지름이 조금 크게 나왔습니다. 교과서 63쪽도 정지 궤도 계산을 다룹니다.

유도 · 위성의 에너지와 탈출 속력 · 교과서 63~65쪽, 73쪽

원 궤도 위성의 역학적 에너지는 음수다

  1. 원 궤도의 $v^2 = GM/r$ 에서 운동 에너지.

    $$K = \tfrac12mv^2 = \frac{GMm}{2r}$$

  2. 중력 퍼텐셜 에너지 (무한히 먼 곳 기준).

    $$U = -\frac{GMm}{r}$$

  3. 더하면 역학적 에너지는 운동 에너지의 음수다.

    $$E = K + U = -\frac{GMm}{2r} = -K$$

  4. 높은 궤도로 옮기려면 에너지를 넣어야 하지만($E$ 증가), 그곳의 속력은 더 느리다.

    $$r\uparrow\ \Rightarrow\ E\uparrow,\ \ K\downarrow,\ \ v\downarrow$$

  5. 탈출 속력: 무한히 먼 곳에서도 $K \ge 0$ 이려면 지표에서 $E \ge 0$ 이어야 한다.

    $$\tfrac12mv_{esc}^2 - \frac{GMm}{R} = 0\ \Rightarrow\ v_{esc} = \sqrt{\frac{2GM}{R}}$$

  6. 지구 ($GM = 3.986\times10^{14}$ m³/s², $R = 6.371\times10^6$ m).

    $$v_{esc} = 11.2\ \text{km/s} = \sqrt2\times7.9\ \text{km/s}\ \ (\text{지표 원 궤도 속력})$$

압력은 분자 충돌의 평균이다

분자는 크기를 무시할 수 있고, 벽·다른 분자와 탄성 충돌만 하며, 충돌 외에는 힘을 주고받지 않는다고 가정합니다 (이상 기체).

한 분자가 벽에 부딪칠 때마다 운동량 $2mv_x$ 를 전달하므로, 부피 $V$ 안의 분자 $N$ 개가 만드는 압력은

$$P = \frac13\frac{N}{V}m\langle v^2\rangle\quad\Rightarrow\quad PV = \frac23N\langle K\rangle$$

실험식 $PV = nRT = NkT$ 와 비교하면

$$\langle K\rangle = \tfrac32kT,\qquad v_{rms} = \sqrt{\frac{3kT}{m}}$$
온도의 미시적 의미

절대 온도는 분자 하나의 평균 병진 운동 에너지에 비례합니다.

예: 300 K 질소 분자의 $v_{rms} \approx 517$ m/s. 같은 온도에서 가벼운 분자일수록 빠릅니다.

$k = 1.38\times10^{-23}$ J/K (볼츠만 상수), $R = N_Ak = 8.31$ J/(mol·K)

유도 · 기체 분자 운동 모형 · 교과서 70~72쪽 식 (Ⅰ. 5-2~7)

분자 한 개의 충돌에서 이상 기체 방정식까지

  1. 한 변이 $L$ 인 정육면체. 분자가 오른쪽 벽과 탄성 충돌하면 $x$ 성분만 뒤집힌다.

    $$\Delta p_x = mv_x - (-mv_x) = 2mv_x$$

  2. 같은 벽에 다시 부딪치기까지 왕복 시간.

    $$\Delta t = \frac{2L}{v_x}$$

  3. 분자 하나가 벽에 주는 평균 힘.

    $$F_1 = \frac{\Delta p_x}{\Delta t} = \frac{mv_x^2}{L}$$

  4. $N$ 개를 더하고 제곱 평균 $\langle v_x^2\rangle$ 로 쓴다.

    $$F = \frac mL\big(v_{x1}^2 + \cdots + v_{xN}^2\big) = \frac{Nm}{L}\langle v_x^2\rangle$$

  5. 벽의 넓이 $L^2$ 로 나누고, 방향이 고르므로 $\langle v_x^2\rangle = \tfrac13\langle v^2\rangle$.

    $$P = \frac{Nm\langle v^2\rangle}{3V}\ \Rightarrow\ PV = \tfrac23N\langle K\rangle$$

  6. 실험식 $PV = NkT$ 와 비교한다 ($M$: 몰질량).

    $$\langle K\rangle = \tfrac32kT,\qquad v_{rms} = \sqrt{\frac{3kT}{m}} = \sqrt{\frac{3RT}{M}}$$
교과서 73쪽 '더 알아보기'는 300 K 수소 분자의 rms 속력을 약 2200 m/s로 적었는데, √(3RT/M)에 M = 2.016 g/mol을 넣으면 1.93 km/s입니다. 탈출 속력의 1/6(1.87 km/s)보다 크다는 결론은 같습니다.

유도 · 등온 과정과 열용량 · 교과서 75쪽, 78쪽 식 (Ⅰ. 5-12)

등온 과정의 일, 그리고 정적·정압 몰 열용량

  1. 등온선 $P = NkT/V$ 를 부피로 적분한다 ($T$ 는 상수라 밖으로 나온다).

    $$W = \int_{V_i}^{V_f}\frac{NkT}{V}\,dV = NkT\ln\frac{V_f}{V_i}$$

  2. 이상 기체의 내부 에너지는 온도만의 함수라 $\Delta U = 0$.

    $$Q = W = NkT\ln\frac{V_f}{V_i}$$

  3. 등적 과정: $W = 0$ 이라 받은 열이 모두 내부 에너지가 된다.

    $$Q_V = \Delta U = \frac f2nR\,\Delta T\ \Rightarrow\ C_V = \frac f2R$$

  4. 등압 과정: 기체가 한 일 $P\Delta V = nR\Delta T$ 만큼 열이 더 든다.

    $$Q_P = \Delta U + P\Delta V = \Big(\frac f2 + 1\Big)nR\,\Delta T\ \Rightarrow\ C_P = C_V + R$$

  5. 두 열용량의 비가 단열 지수다.

    $$\gamma = \frac{C_P}{C_V} = \frac{f + 2}{f}$$

예: 단원자 기체 $C_V = \tfrac32R = 12.5$ J/(mol·K), $C_P = \tfrac52R = 20.8$ J/(mol·K), $\gamma = 5/3$.

유도 · 단열 과정 · 교과서 78~79쪽 식 (Ⅰ. 5-13)

미분 두 개를 엮어 PVγ = 일정 얻기

  1. 단열이므로 $Q = 0$. 제1법칙을 미소 변화로 쓴다.

    $$dU = -P\,dV$$

  2. $U = \tfrac f2NkT$ 를 미분한다.

    $$dU = \frac f2Nk\,dT$$

  3. $PV = NkT$ 의 양변을 미분한다 (곱의 미분).

    $$P\,dV + V\,dP = Nk\,dT$$

  4. $Nk\,dT$ 를 없애고 2를 곱해 정리한다.

    $$\frac f2\big(P\,dV + V\,dP\big) = -P\,dV\ \Rightarrow\ (f+2)P\,dV + fV\,dP = 0$$

  5. $fPV$ 로 나누고 $\gamma = (f+2)/f$ 로 쓴 뒤 적분한다.

    $$\gamma\frac{dV}{V} + \frac{dP}{P} = 0\ \Rightarrow\ \gamma\ln V + \ln P = \text{상수}$$

  6. 결과. $P = NkT/V$ 를 넣으면 온도 관계, 제1법칙에서 한 일.

    $$PV^\gamma = \text{일정},\quad TV^{\gamma-1} = \text{일정},\quad W = -\Delta U = \frac{P_iV_i - P_fV_f}{\gamma - 1}$$

열기관 · 교과서 84~86쪽

열효율과 카르노 기관

열기관은 고온 열저장고에서 $Q_H$ 를 받아 일 $W$ 를 하고, 저온 열저장고에 $Q_C$ 를 버리며 순환합니다. 한 순환에서 $\Delta U = 0$ 이므로 $W = Q_H - Q_C$.

$$e = \frac{W}{Q_H} = 1 - \frac{Q_C}{Q_H}$$

카르노 기관: 등온 팽창 → 단열 팽창 → 등온 압축 → 단열 압축의 가역 순환. 두 온도 사이에서 가능한 가장 높은 효율을 가집니다.

$$\frac{Q_C}{Q_H} = \frac{T_C}{T_H},\qquad e_C = 1 - \frac{T_C}{T_H}$$
예제

500 K와 300 K 사이의 카르노 기관이 한 순환에 1000 J을 흡수한다. 효율, 일, 버리는 열은?

풀이 보기

$e = 1 - 300/500 = 0.40$, $W = 400$ J, $Q_C = 600$ J

엔트로피: 고온부 $-1000/500 = -2.0$ J/K, 저온부 $+600/300 = +2.0$ J/K, 합 0 (가역).

유도 · 카르노 기관 · 교과서 85~86쪽

네 과정의 열을 계산해 카르노 효율 얻기

  1. 1→2 등온 팽창 ($T_H$): 흡수한 열 = 기체가 한 일.

    $$Q_H = NkT_H\ln\frac{V_2}{V_1}$$

  2. 3→4 등온 압축 ($T_C$): 방출한 열의 크기.

    $$Q_C = NkT_C\ln\frac{V_3}{V_4}$$

  3. 2→3, 4→1 단열 과정에서는 $TV^{\gamma-1}$ 이 일정하다.

    $$T_HV_2^{\gamma-1} = T_CV_3^{\gamma-1},\qquad T_HV_1^{\gamma-1} = T_CV_4^{\gamma-1}$$

  4. 두 식을 나누면 부피비가 같아진다.

    $$\Big(\frac{V_2}{V_1}\Big)^{\gamma-1} = \Big(\frac{V_3}{V_4}\Big)^{\gamma-1}\ \Rightarrow\ \frac{V_2}{V_1} = \frac{V_3}{V_4}$$

  5. 그래서 1·2단계의 로그가 지워진다.

    $$\frac{Q_C}{Q_H} = \frac{T_C}{T_H}$$

  6. 효율 (식 Ⅰ. 6-1). 같은 식은 $Q_H/T_H = Q_C/T_C$, 곧 한 순환의 엔트로피 변화가 0이라는 뜻이다.

    $$e_C = 1 - \frac{Q_C}{Q_H} = 1 - \frac{T_C}{T_H}$$

    $$dS = \frac f2Nk\,\frac{dT}{T} + Nk\,\frac{dV}{V}$$

  3. 적분한다.

    $$\Delta S = \frac f2Nk\ln\frac{T_f}{T_i} + Nk\ln\frac{V_f}{V_i}$$

  4. 자유 팽창 ($T_f = T_i$): 2 mol 이 부피 3배로.

유도 · 통계적 엔트로피 · 교과서 90~92쪽

겹침수를 세어 자유 팽창의 엔트로피 다시 구하기

  1. 동전 $N$ 개 중 앞면이 $n$ 개인 미시 상태의 수는 조합이다.

    $$W(n) = {}_N\mathrm C_n = \frac{N!}{n!\,(N - n)!}$$

  2. 예: $N = 6$, $n = 3$.

    $$W = \frac{6!}{3!\,3!} = \frac{720}{36} = 20$$

  3. 기체 분자 $N$ 개가 부피 $V$ 에서 $2V$ 로 퍼지면 분자 하나가 있을 수 있는 자리가 2배가 된다.

    $$\frac{W_f}{W_i} = 2^N$$

  4. 볼츠만 식에 넣는다.

    $$\Delta S = k\ln W_f - k\ln W_i = k\ln2^N = Nk\ln2$$

  5. 앞 슬라이드의 열역학 결과($Nk = nR$)와 비교한다.

    $$\Delta S = nR\ln\frac{2V}{V} = nR\ln2\ \ \checkmark$$

  6. 1 mol 이면 $\Delta S = 5.76$ J/K. 거꾸로 분자가 모두 한쪽에 모일 확률은 $(1/2)^{6.02\times10^{23}}$ 이라 사실상 0이다.

    $$\frac{W_i}{W_f} = 2^{-N} = e^{-\Delta S/k}$$

정리

역학에서 가져갈 것

  • 운동 방정식 $m\ddot{\vec r} = \sum\vec F$ 는 미분방정식이고, 초기 조건이 해를 정한다.
  • 선형 저항은 $e^{-t/\tau}$ 로 종단 속도에 다가가고, 제곱 저항은 $v_T = \sqrt{mg/c}$.
  • 보존력은 $\vec F = -\nabla U$. 운동 가능 영역은 $E \ge U$.
  • 충돌 동안 계의 운동량은 보존된다. $Q = K_i - K_f$, 비탄성이면 $Q \gt 0$.
  • 회전 관성 $I = \int r^2dm$, 평행축 정리는 언제나, 수직축 정리는 얇은 판에서만.
  • $d\vec L/dt = \vec\tau_{외}$. 외부 돌림힘이 없으면 각운동량 보존.
  • 굴림 운동: $v_{cm} = R\omega$, 가속도는 $I/MR^2$ 로 정해진다.
  • 케플러 제2법칙은 각운동량 보존, $T^2 = 4\pi^2a^3/GM$, 원 궤도 $v = \sqrt{GM/r}$.
  • $\langle K\rangle = \tfrac32kT$, $U = \tfrac f2nRT$, $\Delta U = Q - W$.
  • $e = 1 - Q_C/Q_H \le 1 - T_C/T_H$, $\Delta S \ge 0$, $S = k\ln W$.

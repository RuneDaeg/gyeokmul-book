## 2. 2022 개정 고급물리학의 구성

- 선수 과목: 일반선택 「물리학」
- 긴밀히 연계되는 과목: 진로선택 「역학과 에너지」·「전자기와 양자」, 융합선택 「물리학 실험」

| | [12고물01-03] 회전 관성과 각운동량 보존 법칙으로 물체의 회전 운동 설명 | 확인 |

| | 양자역학 수립 과정: 빛과 물질의 이중성, 보어 수소 원자 모형과 스펙트럼, 슈뢰딩거 방정식 소개 | 내용 확인, **번호 미확정** |
| | [12고물04-04] 상보성 원리와 불확정성 원리 설명 | 확인 |
| | [12고물04-05] 1차원 무한 퍼텐셜 상자의 파동 함수와 에너지 준위를 정량 설명, 반도체 띠 이론, 나노 물리학 전망 토의. 고려 사항: 나노튜브·그래핀 조사·발표 | 확인 |

**연계 과목으로 옮겨 간 내용**

- 「물리학」(일반선택): 저항의 직렬·병렬 연결과 소비 전력, 축전기의 기본 개념
- 「역학과 에너지」(진로선택): 시공간과 운동(포물선 운동부터 행성의 궤도 운동), 열과 에너지(열과 소리의 전달)
- 「전자기와 양자」(진로선택): 빛과 정보 통신 (빛의 간섭·편광·굴절 등 기본 성질)

- **p3 ·** 운동학의 영어는 *Kinematics* 입니다. *Kinetics* 는 힘과 운동의 관계를 다룹니다.
- **p4 ·** "소규모 입자계 → 입자물리학"은 질점(입자) 역학, 이체 문제의 오역입니다. 입자물리학은 기본 입자를 다루는 별개 분야입니다.
- **p5 ·** 프린키피아 출간은 1687년입니다. '최소 작용 원리'는 엄밀히 정류(정상) 작용 원리입니다.
- **p6 ★** "공간의 역학적 성질이 균일하지 않음 → 비등방성"이라고 썼습니다. 균일하지 않은 것은 비균질성이고 비등방성은 별개 개념입니다. 비관성계에서는 둘 다 성립하지 않습니다.
- **p11 ·** 제목은 '등속 원운동'인데 식은 일반 평면 극좌표 운동입니다. '구면좌표계'보다 '평면 극좌표'가 정확합니다.
- **p14 ·** 제3법칙에서 "힘의 크기는 같다"만 쓰고 "방향은 반대이고 같은 작용선 위에 있다"가 빠졌습니다.
- **p18 ★** 혼돈(카오스)을 결정론의 반례로 제시했습니다.

- **p26 ·** 제곱형 저항 $F=-cv^2$ 에서는 방향 정보가 사라집니다. $\vec F = -c\lvert\vec v\rvert\vec v$ 로 쓰세요.

**회전 운동**

- **p95 ★** "$v = dr/dt = r\omega$ (반지름이 일정한 원운동)"이라고 썼습니다. 반지름이 일정하면 $dr/dt=0$ 이므로 $v = ds/dt = r\omega$ 로 쓰세요.
- **p97·98·110·117 ★** $\vec L = \vec r\times\vec p = I\vec\omega$, $\vec\tau = d\vec L/dt = I\vec\alpha$ 를 '정의'로 제시했습니다.
  - $\vec L = I\vec\omega$ 와 $\tau = I\alpha$ 는 고정축(주축) 회전에서만 성립합니다.
  - 돌림힘의 정의는 $\vec r\times\vec F$ 이고, $d\vec L/dt=\vec\tau$ 는 정리입니다.
- **p106 ★★** 4-1표 4번을 보세요.
- **p114 ★** 회전 일-에너지 유도가 성립하지 않습니다.
  - "$F\,dr \to mr\frac{d\omega}{dt}dr \to \dots$"에서 고정축 회전의 변위는 호 길이 $ds = r\,d\theta$ 이고 $dr=0$ 입니다.
  - $F_t\,ds = m\frac{dv}{dt}ds = mv\,dv = mr^2\omega\,d\omega$ 로 고치세요.
- **p121~122 ★★** 4-1표 5번을 보세요. 3.85 km/h는 '홀로 굴러가는 얇은 원판'의 안정 조건($v^2>gR/3$)입니다.
- **p135 ★★** 4-1표 6번을 보세요.
- **p138 ★** "$\sum\vec p_i=0 \Rightarrow \sum\vec L_i = 0$"은 성립하지 않습니다.
  - 반례: 중심이 고정된 채 회전하는 바퀴는 $\sum\vec p=0$ 이지만 $\vec L\ne0$ 입니다.
  - 정적 평형은 모든 부분이 정지($\vec p_i=0$)해 있는 상태입니다.

### 4-7. 상대성 이론 (101쪽)

**특수 상대론의 배경과 로런츠 변환**

- **p27 ★** "무늬 이동 없음 ⇒ 빛에는 매질이 없다!"는 비약입니다.

  - "광속 불변 가정으로 가장 자연스럽게 설명된다"로 쓰세요.

**특수 상대론의 결과**

- **p51 ★★** 4-1표 23번을 보세요.
- **p75 ★** 4×4 로런츠 행렬로 변환되는 것은 **4-속도** $U^\mu = \gamma_u(c,\vec u)$ 입니다. 3-속도 $dx'/dt'$ 는 행렬로 선형 변환되지 않습니다 (p76의 속도 덧셈식이 비선형인 이유).
- **p79 ·** '상대론적 질량 $\gamma m_0$'은 오류는 아닙니다. 다만 요즘 교재는 불변 질량 $m$ 하나만 쓰고 $\vec p=\gamma m\vec u$ 로 표기하는 추세입니다.
- **p56, p59~71 (확인)** 뮤온 677 m, 헛간 역설($\gamma=2$, $v=\tfrac{\sqrt3}{2}c$), 2025학년도 수능 9번 풀이(ㄴ, ㄷ), 쌍둥이 13.15년을 검산했고 모두 맞습니다.

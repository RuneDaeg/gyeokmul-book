운동의 기술

위치, 속도, 가속도 벡터

$$\vec r(t) = x\hat x + y\hat y + z\hat z,\qquad \vec v = \frac{d\vec r}{dt},\qquad \vec a = \frac{d\vec v}{dt}$$

거꾸로, 가속도를 알면 두 번 적분해서 위치를 얻습니다.

$$\vec v(t) = \vec v_0 + \int_0^t\vec a\,dt',\qquad \vec r(t) = \vec r_0 + \int_0^t\vec v\,dt'$$
원운동에서

반지름 $r$ 인 원 위를 각속도 $\omega$ 로 돌면 $v = r\omega$ 이고, 가속도는

$$a_t = r\alpha\ \ (\text{접선}),\qquad a_c = \frac{v^2}{r} = r\omega^2\ \ (\text{중심 방향})$$

등속 원운동에서도 속도의 방향이 바뀌므로 가속도는 0이 아닙니다.

포물선 운동 · 1

벡터 한 줄로 쓰는 포물선 운동

공기 저항이 없으면 가속도는 $\vec a = \vec g = -g\hat y$ 로 일정합니다.

$$\vec r(t) = \vec r_0 + \vec v_0t + \tfrac12\vec g\,t^2$$

성분으로 나누면 수평은 등속, 연직은 등가속도입니다.

$$x = v_0\cos\theta\,t,\qquad y = v_0\sin\theta\,t - \tfrac12gt^2$$
$$H = \frac{v_0^2\sin^2\theta}{2g},\qquad R = \frac{v_0^2\sin2\theta}{g}$$
예제

$v_0 = 20$ m/s, $\theta = 30^\circ$, $g = 9.8$ m/s²

풀이 보기

$v_x = 17.3$ m/s, $v_y = 10.0$ m/s

최고점 도달 $t = v_y/g = 1.02$ s, $H = 5.10$ m

비행 시간 $2.04$ s, $R = 35.3$ m

같은 $v_0$ 에서 $R$ 이 가장 큰 각은 $45^\circ$ 이고, $30^\circ$ 와 $60^\circ$ 의 $R$ 은 같습니다.

뉴턴 법칙

운동 방정식은 미분방정식이다

$$m\frac{d^2\vec r}{dt^2} = \sum\vec F\big(\vec r,\vec v,t\big)$$
  • 제1법칙: 알짜힘이 0이면 속도가 일정합니다. 이 법칙이 성립하는 기준계가 관성 좌표계입니다.
  • 제2법칙: $\vec F_{net} = d\vec p/dt$ 이고, 질량이 일정하면 $m\vec a$ 입니다.
  • 제3법칙: 두 물체가 서로에게 주는 힘은 크기가 같고 방향이 반대이며 같은 작용선 위에 있습니다. 두 힘은 서로 다른 물체에 작용합니다.
문제를 푸는 순서
  1. 물체 하나를 골라 자유 물체 도형을 그린다.
  2. 좌표축을 정하고 힘을 성분으로 나눈다.
  3. 성분마다 $m\ddot x = \sum F_x$ 를 세운다.
  4. 초기 조건으로 적분 상수를 정한다.

저항력 · 1

선형 저항 속 낙하: 종단 속도

느린 속도의 작은 물체는 속도에 비례하는 저항 $\vec F_D = -b\vec v$ 를 받습니다. 아래쪽을 $+$ 로 잡으면

$$m\frac{dv}{dt} = mg - bv$$

1계 선형 방정식이므로 $v(0) = 0$ 에서

$$v(t) = v_T\big(1 - e^{-t/\tau}\big),\qquad v_T = \frac{mg}{b},\ \ \tau = \frac mb$$

$t = \tau$ 에서 $v_T$ 의 63 %, $t = 3\tau$ 에서 95 %에 이릅니다.

역학 · 07 / 43

저항력 · 2

제곱형 저항과 포물선 궤적의 변화

빠른 물체(공, 사람)는 크기가 $cv^2$ 이고 운동 반대 방향인 저항을 받습니다.

$$\vec F_D = -c\,|\vec v|\,\vec v,\qquad c = \tfrac12 C_D\rho A$$

종단 속도는 $mg = cv_T^2$ 에서 $v_T = \sqrt{mg/c}$ 입니다.

예: 스카이다이버 $m = 80$ kg, $c \approx 0.25$ kg/m 이면 $v_T \approx 56$ m/s.

기존 역학 p26의 $F = -cv^2$ 는 방향이 사라진 표기였습니다. 벡터로 $-c|\vec v|\vec v$ 로 쓰면 성분 방정식이 결합되어 있다는 것도 보입니다.

탄성력과 단진동 · 교과서 19쪽

용수철 진자: 2계 미분방정식의 첫 예

탄성 한계 안에서 탄성력은 변형에 비례합니다 (훅의 법칙 $F = -kx$). 뉴턴 제2법칙에 넣으면

$$m\frac{d^2x}{dt^2} = -kx$$

두 번 미분했을 때 자기 자신에 $-k/m$ 을 곱한 꼴이 되는 함수는 사인·코사인입니다.

$$x(t) = A\cos(\omega t + \phi),\qquad \omega = \sqrt{\frac km},\qquad T = 2\pi\sqrt{\frac mk}$$

진폭 $A$ 와 초기 위상 $\phi$ 는 처음 위치와 속도로 정해집니다. 주기는 진폭과 무관합니다.

예제

$k = 200$ N/m 인 용수철에 0.50 kg 물체를 달아 0.10 m 당겼다 놓았다. 각진동수, 주기, 최대 속력은?

풀이 보기

$\omega = \sqrt{200/0.50} = 20$ rad/s, $T = 2\pi/20 = 0.31$ s

$v_{max} = A\omega = 2.0$ m/s. 에너지로 검산: $\tfrac12kA^2 = 1.0$ J $= \tfrac12mv_{max}^2$

같은 꼴의 방정식이 전자기학의 LC 회로에서 다시 나옵니다.

탐구 활동

컴퓨터로 운동 방정식 풀기 (오일러 방법)

해석적으로 풀기 어려운 제곱형 저항도 짧은 시간 간격 $\Delta t$ 로 나누면 풀 수 있습니다.

$$\vec a_n = \vec g - \frac cm|\vec v_n|\vec v_n,\quad \vec v_{n+1} = \vec v_n + \vec a_n\Delta t,\quad \vec r_{n+1} = \vec r_n + \vec v_n\Delta t$$
  1. 스프레드시트에 $t,\ x,\ y,\ v_x,\ v_y$ 열을 만든다.
  2. $\Delta t = 0.01$ s 로 위 식을 아래로 채운다.
  3. $c = 0$ 일 때 해석해 $R = v_0^2\sin2\theta/g$ 와 비교해 방법을 검증한다.
  4. $c$ 를 바꾸며 최대 도달 거리를 주는 각이 $45^\circ$ 보다 작아지는지 확인한다.
생각해 볼 질문

$\Delta t$ 를 절반으로 줄이면 결과가 얼마나 달라지는가? 그 차이가 수치 해의 오차를 어림하는 방법이 됩니다.

일-에너지 정리

알짜힘이 한 일 = 운동 에너지 변화

$$W_{net} = \int\vec F_{net}\cdot d\vec r = \int m\frac{d\vec v}{dt}\cdot\vec v\,dt = \Delta\Big(\tfrac12mv^2\Big)$$

여기서 일을 계산하는 힘은 알짜힘입니다. 힘 하나가 한 일만으로는 $\Delta K$ 가 정해지지 않습니다.

오개념 바로잡기

"물체를 천천히 들어 올리면 계의 에너지가 일정하다"는 틀렸습니다.

손(외력)이 $mgh$ 의 일을 하므로, 물체와 지구로 이루어진 계의 에너지는 $mgh$ 만큼 증가합니다. 이 에너지가 중력 퍼텐셜 에너지로 저장됩니다.

기존 역학 p40·p52 수정 사항: 계의 에너지 변화는 외력의 일과 같고, 일-에너지 정리의 힘은 알짜힘입니다.

보존력

경로에 무관한 일, 퍼텐셜 에너지

한 일이 경로와 무관하고 처음과 끝 위치로만 정해지는 힘이 보존력입니다.

$$\oint\vec F\cdot d\vec l = 0,\qquad U(B) - U(A) = -\int_A^B\vec F\cdot d\vec l,\qquad \vec F = -\nabla U$$
중력 (지표 근처)$U = mgy$
탄성력$U = \tfrac12kx^2$
만유인력$U = -GMm/r$
비보존력과 에너지 보존

마찰 같은 비보존력이 일을 하면 역학적 에너지 $K+U$ 가 보존되지 않습니다. 그 에너지는 열·소리·변형으로 바뀔 뿐 총에너지는 항상 보존됩니다.

자기력 $q\vec v\times\vec B$ 는 속도에 수직이라 일을 하지 않습니다. 보존력·비보존력과 따로 기억하세요.

기존 역학 p41·p43·p44에서 '비보존력이면 (질량-)에너지 보존이 성립하지 않는다', '강력·약력은 역학적 에너지 보존이 성립하지 않는다'는 서술을 바로잡았습니다.

퍼텐셜 에너지 곡선

E ≥ U 인 곳에서만 움직일 수 있다

$$K = E - U(x) \ge 0$$
  • $E$ 선이 $U$ 곡선보다 위에 있는 구간에서만 운동합니다.
  • $E = U$ 인 점은 전환점입니다. 순간 정지 후 되돌아옵니다.
  • $dU/dx = 0$ 이면 평형점입니다. $d^2U/dx^2 \gt 0$ (골짜기)이면 안정, $\lt0$ (봉우리)이면 불안정 평형입니다.
  • 양쪽 장벽보다 $E$ 가 낮으면 입자는 골짜기에 속박됩니다.
기존 역학 p50은 "역학적 에너지가 퍼텐셜 곡선보다 아래에 있으면 자유롭게 운동"이라고 반대로 서술했습니다.

운동량

충격량과 계의 운동량 보존

$$\vec J = \int\vec F\,dt = \Delta\vec p,\qquad \frac{d\vec P_{계}}{dt} = \sum\vec F_{외}$$

내력은 제3법칙에 따라 쌍으로 상쇄되므로 계의 운동량을 바꾸는 것은 외력뿐입니다.

충돌은 시간이 매우 짧고 내력이 매우 큽니다. 그동안 중력·마찰 같은 외력의 충격량 $\int\vec F_{외}dt$ 는 무시할 수 있어 운동량이 (근사적으로) 보존됩니다.

질량 중심
$$\vec R_{cm} = \frac{\sum m_i\vec r_i}{M},\qquad M\vec a_{cm} = \sum\vec F_{외}$$

외력이 없으면 질량 중심은 등속 운동합니다. 폭발 뒤 파편이 흩어져도 질량 중심은 원래 포물선을 그대로 따라갑니다.

1차원 충돌

반발 계수와 운동 에너지 손실 Q

$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2',\qquad e = -\frac{v_1'-v_2'}{v_1-v_2}$$

탄성 충돌($e = 1$)의 결과:

$$v_1' = \frac{m_1-m_2}{m_1+m_2}v_1 + \frac{2m_2}{m_1+m_2}v_2,\qquad v_2' = \frac{2m_1}{m_1+m_2}v_1 + \frac{m_2-m_1}{m_1+m_2}v_2$$
Q의 정의와 부호
$$K_i = K_f + Q,\qquad Q = \tfrac12\mu\,(1-e^2)\,(v_1-v_2)^2,\ \ \mu = \frac{m_1m_2}{m_1+m_2}$$
  • $Q = 0$: 탄성 충돌 ($e=1$)
  • $Q \gt 0$: 비탄성 충돌. 운동 에너지가 열·소리·변형으로 감 ($e=0$ 이면 완전 비탄성)
  • $Q \lt 0$: 운동 에너지 증가 (화학·용수철 에너지가 풀리는 폭발)
기존 역학 p65는 같은 식 K_i = K_f + Q 를 쓰면서 Q의 부호를 반대로 설명했습니다. 핵반응 관례(Q = K_f − K_i)를 쓰려면 식을 K_i + Q = K_f 로 바꿔야 합니다.

2차원 충돌 · 실험실 좌표계

성분마다 운동량 보존

정지한 $m_2$ 에 $m_1$ 이 $v_1$ 로 부딪혀 각각 $\theta_1$, $\theta_2$ 방향으로 흩어지면

$$\begin{aligned} x:&\ \ m_1v_1 = m_1v_1'\cos\theta_1 + m_2v_2'\cos\theta_2\\ y:&\ \ 0 = m_1v_1'\sin\theta_1 - m_2v_2'\sin\theta_2\end{aligned}$$

탄성 충돌이면 $\tfrac12m_1v_1^2 = \tfrac12m_1v_1'^2 + \tfrac12m_2v_2'^2$ 이 더해집니다.

같은 질량의 탄성 충돌

$m_1 = m_2$ 이면 $\vec v_1 = \vec v_1' + \vec v_2'$ 이고 $v_1^2 = v_1'^2 + v_2'^2$ 입니다.

첫 식을 제곱하면 $v_1^2 = v_1'^2 + v_2'^2 + 2\vec v_1'\cdot\vec v_2'$ 이므로

$$\vec v_1'\cdot\vec v_2' = 0\ \Rightarrow\ \theta_1 + \theta_2 = 90^\circ$$

당구공이 맞은 뒤 두 공이 직각으로 흩어지는 이유입니다 (회전 효과 무시).

심화 · 교과서 밖 · 질량 중심 좌표계

질량 중심과 함께 움직이며 보면 단순해진다

질량 중심 속도 $\vec V_{cm} = \dfrac{m_1\vec v_1 + m_2\vec v_2}{m_1+m_2}$ 로 움직이는 좌표계에서는 계의 운동량이 0입니다.

$$\vec u_i = \vec v_i - \vec V_{cm},\qquad m_1\vec u_1 + m_2\vec u_2 = 0$$
  • 두 입자는 항상 정반대 방향으로 움직입니다.
  • 탄성 충돌이면 각 입자의 속력은 그대로이고 방향만 같은 각만큼 돕니다.
  • 실험실 속도는 다시 $\vec v_i' = \vec u_i' + \vec V_{cm}$ 로 돌아옵니다.
왜 쓰는가

충돌로 '쓸 수 있는' 운동 에너지는 질량 중심 좌표계의 운동 에너지 $\tfrac12\mu v_{rel}^2$ 뿐입니다. $\tfrac12MV_{cm}^2$ 는 운동량 보존 때문에 충돌 뒤에도 남아야 합니다.

완전 비탄성 충돌의 손실 $Q = \tfrac12\mu v_{rel}^2$ 가 바로 이 값입니다.

기체 분자 운동 모형 · 교과서 69~72쪽

압력은 분자 충돌의 평균이다

분자는 크기를 무시할 수 있고, 벽·다른 분자와 탄성 충돌만 하며, 충돌 외에는 힘을 주고받지 않는다고 가정합니다 (이상 기체).

한 분자가 벽에 부딪칠 때마다 운동량 $2mv_x$ 를 전달하므로, 부피 $V$ 안의 분자 $N$ 개가 만드는 압력은

$$P = \frac13\frac{N}{V}m\langle v^2\rangle\quad\Rightarrow\quad PV = \frac23N\langle K\rangle$$

실험식 $PV = nRT = NkT$ 와 비교하면

$$\langle K\rangle = \tfrac32kT,\qquad v_{rms} = \sqrt{\frac{3kT}{m}}$$
온도의 미시적 의미

절대 온도는 분자 하나의 평균 병진 운동 에너지에 비례합니다.

예: 300 K 질소 분자의 $v_{rms} \approx 517$ m/s. 같은 온도에서 가벼운 분자일수록 빠릅니다.

$k = 1.38\times10^{-23}$ J/K (볼츠만 상수), $R = N_Ak = 8.31$ J/(mol·K)

300 K 이상 기체 1 mol 의 부피를 두 배로 늘린다. ① 등온 팽창이면 흡수한 열은? ② 단원자 기체가 단열 팽창하면 나중 온도는?

풀이 보기

① $Q = W = (8.31)(300)\ln2 \approx 1.73\times10^3$ J

② $TV^{\gamma-1}$ 일정, $\gamma - 1 = 2/3$: $T_f = 300\times(1/2)^{2/3} \approx 189$ K. 외부에 한 일만큼 내부 에너지가 줄어 온도가 내려갑니다 (구름이 생기는 원리).

열기관 · 교과서 84~86쪽

열효율과 카르노 기관

열기관은 고온 열저장고에서 $Q_H$ 를 받아 일 $W$ 를 하고, 저온 열저장고에 $Q_C$ 를 버리며 순환합니다. 한 순환에서 $\Delta U = 0$ 이므로 $W = Q_H - Q_C$.

$$e = \frac{W}{Q_H} = 1 - \frac{Q_C}{Q_H}$$

카르노 기관: 등온 팽창 → 단열 팽창 → 등온 압축 → 단열 압축의 가역 순환. 두 온도 사이에서 가능한 가장 높은 효율을 가집니다.

$$\frac{Q_C}{Q_H} = \frac{T_C}{T_H},\qquad e_C = 1 - \frac{T_C}{T_H}$$
예제

500 K와 300 K 사이의 카르노 기관이 한 순환에 1000 J을 흡수한다. 효율, 일, 버리는 열은?

풀이 보기

$e = 1 - 300/500 = 0.40$, $W = 400$ J, $Q_C = 600$ J

엔트로피: 고온부 $-1000/500 = -2.0$ J/K, 저온부 $+600/300 = +2.0$ J/K, 합 0 (가역).

기존 역학 p268은 저온 등온 압축의 열을 T_h로 썼습니다 (T_c가 맞음).

엔트로피 · 교과서 87~90쪽

가역 경로로 계산하는 상태 함수

$$\Delta S = \int_i^f\frac{dQ_{\text{가역}}}{T}$$

엔트로피는 상태 함수입니다. 실제 과정이 비가역이어도, 같은 처음·끝 상태를 잇는 가역 경로를 하나 골라 계산하면 됩니다.

자유 팽창

단열 용기 안에서 기체가 진공으로 퍼지면 $Q = 0,\ W = 0$ 이라 온도가 그대로입니다. 같은 처음·끝을 잇는 등온 가역 팽창으로 계산하면

$$\Delta S = nR\ln\frac{V_f}{V_i}\gt 0$$

2 mol, 부피 3배: $\Delta S = 18.3$ J/K

열역학 제2법칙

닫힌계의 엔트로피는 증가하거나 일정할 뿐 감소하지 않는다 ($\Delta S \ge 0$, 가역일 때만 등호).

예: 1000 J 이 400 K 물체에서 300 K 물체로 흐르면 $\Delta S = -\tfrac{1000}{400} + \tfrac{1000}{300} = +0.83$ J/K. 반대 방향은 저절로 일어나지 않습니다.

효율 1인 열기관을 만들 수 없는 이유도 이것입니다. $Q_C = 0$ 이면 고온부의 엔트로피만 줄어듭니다.

기존 역학 p273의 dS = dQ/T는 가역 열 dQ_rev로 써야 하고, 비가역에서는 dS > dQ/T입니다.

통계적 엔트로피 · 교과서 90~93쪽

S = k ln W: 확률이 큰 상태로 간다

$$S = k\ln W$$

$W$ 는 하나의 거시 상태(예: 앞면 개수)에 대응하는 미시 상태(예: 앞뒤의 순서)의 수, 곧 겹침수입니다.

동전 6개: 앞면 수0123456
W1615201561

전체 64가지 중 '앞면 3개'가 20가지(31 %)로 가장 많습니다.

기체로 옮기면

분자 $N$ 개가 상자 왼쪽 절반에 모두 모여 있을 확률은 $(1/2)^N$. $N = 100$ 이면 $8\times10^{-31}$, 실제 기체($N\sim10^{23}$)라면 사실상 0입니다.

그래서 계는 겹침수가 큰(엔트로피가 큰) 거시 상태로 저절로 갑니다. 제2법칙은 확률의 법칙입니다.

기존 역학 p250은 분자 하나의 운동량을 '구 표면 위의 점'으로 두고 부피로 세는 논리 오류가 있었고, p286은 ∂S/∂N↑를 S로 썼습니다. 교과서는 동전 4개 예시로 다룹니다 (91쪽).

정리

역학에서 가져갈 것

  • 운동 방정식 $m\ddot{\vec r} = \sum\vec F$ 는 미분방정식이고, 초기 조건이 해를 정한다.
  • 선형 저항은 $e^{-t/\tau}$ 로 종단 속도에 다가가고, 제곱 저항은 $v_T = \sqrt{mg/c}$.
  • 보존력은 $\vec F = -\nabla U$. 운동 가능 영역은 $E \ge U$.
  • 충돌 동안 계의 운동량은 보존된다. $Q = K_i - K_f$, 비탄성이면 $Q \gt 0$.
  • 관성 모멘트 $I = \int r^2dm$, 평행축 정리는 언제나, 수직축 정리는 얇은 판에서만.
  • $d\vec L/dt = \vec\tau_{외}$. 외부 돌림힘이 없으면 각운동량 보존.
  • 굴림 운동: $v_{cm} = R\omega$, 가속도는 $I/MR^2$ 로 정해진다.
  • 케플러 제2법칙은 각운동량 보존, $T^2 = 4\pi^2a^3/GM$, 원 궤도 $v = \sqrt{GM/r}$.
  • $\langle K\rangle = \tfrac32kT$, $U = \tfrac f2nRT$, $\Delta U = Q - W$.
  • $e = 1 - Q_C/Q_H \le 1 - T_C/T_H$, $\Delta S \ge 0$, $S = k\ln W$.

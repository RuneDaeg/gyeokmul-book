벡터 · 1

성분, 크기, 단위 벡터

직교 좌표에서 벡터는 세 성분으로 씁니다.

$$\vec A = A_x\hat x + A_y\hat y + A_z\hat z,\qquad A = |\vec A| = \sqrt{A_x^2 + A_y^2 + A_z^2}$$

크기가 1인 단위 벡터는 방향만 나타냅니다.

$$\hat A = \frac{\vec A}{A}$$

벡터는 크기와 방향만 같으면 어디로 옮겨도 같은 벡터입니다. 덧셈은 교환·결합 법칙이 성립합니다.

물리량 분류

벡터: 변위, 속도, 가속도, 힘, 운동량, 전기장 $\vec E$, 자기장 $\vec B$, 유속(속도장)

스칼라: 질량, 시간, 에너지, 일, 전하, 전위, 체적 유량

기존 유인물 p3은 '유량'을 벡터의 예로 들었는데 체적 유량은 스칼라입니다. 벡터인 것은 유속(속도장)입니다.

벡터 · 2

내적: 같은 방향 성분끼리의 곱

$$\vec A\cdot\vec B = AB\cos\theta = A_xB_x + A_yB_y + A_zB_z$$
  • 결과는 스칼라입니다.
  • $\vec A\perp\vec B$ 이면 0입니다.
  • $\hat x\cdot\hat x = 1,\ \hat x\cdot\hat y = 0$
물리에서 쓰는 곳

일: $W = \vec F\cdot\Delta\vec r = F\,\Delta r\cos\theta$

전기 선속: $\Phi_E = \vec E\cdot\vec A$

일률: $P = \vec F\cdot\vec v$

벡터 · 3

외적: 두 벡터에 수직인 벡터

$$|\vec A\times\vec B| = AB\sin\theta$$

방향은 오른손 법칙을 따릅니다. 네 손가락을 $\vec A$ 에서 $\vec B$ 쪽으로 감으면 엄지가 가리키는 쪽입니다.

$$\vec A\times\vec B = \begin{vmatrix}\hat x & \hat y & \hat z\\ A_x & A_y & A_z\\ B_x & B_y & B_z\end{vmatrix},\qquad \vec B\times\vec A = -\vec A\times\vec B$$

$\hat x\times\hat y = \hat z,\ \hat y\times\hat z = \hat x,\ \hat z\times\hat x = \hat y$. 같은 벡터끼리의 외적은 0입니다.

물리에서 쓰는 곳

돌림힘: $\vec\tau = \vec r\times\vec F$

각운동량: $\vec L = \vec r\times\vec p$

로런츠 힘: $\vec F = q\vec v\times\vec B$

비오-사바르 법칙: $d\vec B\propto I\,d\vec l\times\hat r$

좌표계

대칭에 맞는 좌표를 고르면 계산이 짧아진다

좌표계 · 잘 맞는 대칭좌표와 범위직교 좌표로
평면 극좌표원운동, 행성 궤도$r\ge0,\ 0\le\phi\lt2\pi$$x=r\cos\phi,\ y=r\sin\phi$
원통 좌표긴 직선 도선, 솔레노이드$s\ge0,\ 0\le\phi\lt2\pi,\ z$$x=s\cos\phi,\ y=s\sin\phi,\ z=z$
구면 좌표점전하, 대전된 구$r\ge0,\ 0\le\theta\le\pi,\ 0\le\phi\lt2\pi$$x=r\sin\theta\cos\phi,\ y=r\sin\theta\sin\phi,\ z=r\cos\theta$
미소 요소

원통: $dV = s\,ds\,d\phi\,dz$ · 구면: $dV = r^2\sin\theta\,dr\,d\theta\,d\phi$, 반지름 $r$ 인 구면의 면적 요소 $dA = r^2\sin\theta\,d\theta\,d\phi$

기존 OT 슬라이드 p60은 제목이 '구면좌표계'인데 내용이 원통좌표계였습니다. 원통 좌표의 반지름 기호는 여기서 $s$ 로 통일했습니다.

미분 · 1

미분계수와 도함수

$$f'(a) = \lim_{h\to0}\frac{f(a+h)-f(a)}{h}$$

$x=a$ 에서 미분 가능하려면 좌·우 미분계수가 같아야 합니다.

$$\lim_{h\to0^-}\frac{f(a+h)-f(a)}{h} = \lim_{h\to0^+}\frac{f(a+h)-f(a)}{h}$$

미분 가능하면 연속이지만, 연속이라고 미분 가능한 것은 아닙니다 (예: $|x|$ 의 $x=0$).

운동에서

속도 $\vec v = \dfrac{d\vec r}{dt}$, 가속도 $\vec a = \dfrac{d\vec v}{dt} = \dfrac{d^2\vec r}{dt^2}$

1차원의 $v_x = dx/dt$ 는 부호가 있는 속도 성분입니다. 순간 속력은 $|\vec v| = ds/dt$ (경로 길이의 변화율)입니다.

기존 OT p28과 유인물 p7은 미분 가능 조건을 '도함수의 좌·우 극한'으로 썼고, 순간 속력을 $dx/dt$ 로 썼습니다. 여기서 바로잡았습니다.

미분 · 2

자주 쓰는 규칙

상수$\dfrac{d}{dx}c = 0$
거듭제곱$\dfrac{d}{dx}x^n = nx^{n-1}$
지수·로그$\dfrac{d}{dx}e^{kx} = ke^{kx},\ \ \dfrac{d}{dx}\ln x = \dfrac1x$
삼각함수$\dfrac{d}{dx}\sin kx = k\cos kx,\ \ \dfrac{d}{dx}\cos kx = -k\sin kx$
곱$(fg)' = f'g + fg'$
연쇄 법칙

합성함수 $F = f\circ g$, 곧 $F(x) = f(g(x))$ 이면

$$\frac{dF}{dx} = \frac{df}{dg}\frac{dg}{dx}$$

예: $\dfrac{d}{dt}\cos(\omega t+\phi) = -\omega\sin(\omega t+\phi)$

유도 · 정의로 직접 미분하기

거듭제곱, 사인, 곱의 미분을 정의에서 끌어내기

  1. 출발점은 미분계수의 정의다.

    $$f'(x) = \lim_{h\to0}\frac{f(x+h) - f(x)}{h}$$

  2. $f = x^n$: 이항 전개한다.

    $$(x+h)^n = x^n + nx^{n-1}h + \tfrac{n(n-1)}{2}x^{n-2}h^2 + \cdots$$

  3. $x^n$ 을 빼고 $h$ 로 나누면, $h$ 가 곱해진 항은 $h\to0$ 에서 모두 사라진다.

    $$\frac{(x+h)^n - x^n}{h} = nx^{n-1} + \big(h\text{ 가 곱해진 항}\big)\ \to\ nx^{n-1}$$

  4. $f = \sin x$: 덧셈 정리로 펼친다.

    $$\frac{\sin(x+h) - \sin x}{h} = \sin x\,\frac{\cos h - 1}{h} + \cos x\,\frac{\sin h}{h}$$

  5. 작은 각에서 $\dfrac{\sin h}{h}\to1$, $\dfrac{\cos h - 1}{h}\to0$ 이다 ($h$ 는 라디안).

    $$\frac{d}{dx}\sin x = \cos x$$

  6. 곱 $fg$: 가운데에 $f(x)g(x+h)$ 를 빼고 더해 두 덩어리로 나눈다.

    $$\frac{f(x{+}h)g(x{+}h) - fg}{h} = \frac{f(x{+}h) - f}{h}\,g(x{+}h) + f\,\frac{g(x{+}h) - g}{h} \to f'g + fg'$$

미분 · 3

편미분과 기울기: 퍼텐셜에서 힘으로

여러 변수 함수 $f(x,y,z)$ 에서 한 변수만 바꿀 때의 변화율이 편미분입니다.

$$\nabla f = \frac{\partial f}{\partial x}\hat x + \frac{\partial f}{\partial y}\hat y + \frac{\partial f}{\partial z}\hat z$$

$\nabla f$ 는 $f$ 가 가장 빨리 커지는 방향을 가리키고, 크기는 그 변화율입니다.

보존력과 퍼텐셜
$$\vec F = -\nabla U,\qquad \vec E = -\nabla V$$

예: $U = \tfrac12 k(x^2+y^2)$ 이면 $\vec F = -k(x\hat x + y\hat y)$ 로 원점을 향합니다.

적분 · 1

정적분과 부정적분

$F'(x) = f(x)$ 이면

$$\int f(x)\,dx = F(x) + C,\qquad \int_a^b f(x)\,dx = F(b) - F(a)$$

순변화 정리: 변화율을 적분하면 순변화량이 됩니다.

$$x(t) - x(0) = \int_0^t v_x(t')\,dt'$$
등가속도 운동
$$v = v_0 + at,\qquad x = x_0 + v_0t + \tfrac12at^2$$

두 번 적분할 때마다 적분 상수가 하나씩 생기고, 초기 조건 $x_0,\ v_0$ 가 그 상수를 정합니다.

유도 · 적분과 운동 · 교과서 13~14쪽

등가속도 운동의 세 식을 적분으로 얻기

  1. 가속도 $a$ 가 일정하다. $a = dv/dt$ 의 양변을 $0$ 부터 $t$ 까지 적분한다.

    $$\int_{v_0}^{v}dv' = \int_0^t a\,dt'\ \Rightarrow\ v = v_0 + at$$

  2. $v = dx/dt$ 를 다시 적분한다.

    $$x - x_0 = \int_0^t(v_0 + at')\,dt' = v_0t + \tfrac12at^2$$

  3. 그래프로 보면: $v$-$t$ 그래프 아래 사다리꼴의 넓이가 변위다.

    $$x - x_0 = \frac{(v_0 + v)\,t}{2}$$

  4. 시간이 없는 식: 연쇄 법칙으로 가속도를 위치에 대한 미분으로 바꾼다.

    $$a = \frac{dv}{dt} = \frac{dv}{dx}\frac{dx}{dt} = v\frac{dv}{dx}$$

  5. $v\,dv = a\,dx$ 를 적분한다.

    $$\tfrac12\big(v^2 - v_0^2\big) = a(x - x_0)\ \Rightarrow\ v^2 = v_0^2 + 2a(x - x_0)$$

  6. 예: 20 m/s 로 달리던 차가 $-5.0$ m/s² 로 제동한다. 정지 거리와 시간은?

    $$x - x_0 = \frac{0 - 20^2}{2(-5.0)} = 40\ \text{m},\qquad t = \frac{0 - 20}{-5.0} = 4.0\ \text{s}$$

적분 · 2

선적분과 면적분

선적분: 경로를 따라
$$W = \int_{A}^{B}\vec F\cdot d\vec l$$

보존력이면 경로에 관계없이 같고, 닫힌 경로에서는 $\oint\vec F\cdot d\vec l = 0$ 입니다.

암페어 법칙 $\oint\vec B\cdot d\vec l = \mu_0 I_{enc}$ 도 선적분입니다.

면적분: 곡면을 지나는 양
$$\Phi_E = \int_S\vec E\cdot d\vec A$$

$d\vec A$ 는 면적 요소의 크기와 면에 수직인 방향을 함께 가집니다. 닫힌 곡면에서는 바깥쪽이 양의 방향입니다.

가우스 법칙 $\oint\vec E\cdot d\vec A = Q_{in}/\varepsilon_0$ 이 면적분입니다.

적분 · 3

미소 질량과 미소 전하

분포밀도미소 질량
선$\lambda$ (kg/m)$dm = \lambda\,dx$
면$\sigma$ (kg/m²)$dm = \sigma\,dA$
부피$\rho$ (kg/m³)$dm = \rho\,dV$

전하도 같은 방식으로 $dq = \lambda\,dl,\ \sigma\,dA,\ \rho\,dV$ 로 씁니다.

예: 반지름 R인 원판 (면밀도 σ)

폭 $dr$ 인 고리의 넓이는 $2\pi r\,dr$ 이므로

$$dm = \sigma\,2\pi r\,dr,\qquad M = \int_0^R\sigma\,2\pi r\,dr = \sigma\pi R^2$$

중심각 $d\theta$ 인 부채꼴 조각이면 $dm = \tfrac12\sigma R^2\,d\theta$ 입니다.

기존 유인물 p21의 답 "dm = ½R²dθ"에는 면밀도 σ가 빠져 있었습니다.

미분방정식

OT · 19 / 25

미분방정식 · 1

1계 선형: 지수 함수로 다가가기

$$\frac{dy}{dt} = -\frac{y}{\tau}\quad\Longrightarrow\quad y(t) = y(0)\,e^{-t/\tau}$$

변수를 나누어 적분합니다: $\displaystyle\int\frac{dy}{y} = -\int\frac{dt}{\tau}$, 곧 $\ln y = -t/\tau + C$.

$$\frac{dy}{dt} = \frac{y_\infty - y}{\tau}\quad\Longrightarrow\quad y(t) = y_\infty + \big(y(0)-y_\infty\big)e^{-t/\tau}$$
같은 꼴의 물리

선형 저항 속 낙하: $\dfrac{dv}{dt} = g - \dfrac bm v$, $\tau = m/b$

LR 회로 (교과서 132쪽): $L\dfrac{dI}{dt} = \mathcal E - IR$, $\tau = L/R$

RC 회로: $R\dfrac{dq}{dt} = \mathcal E - \dfrac qC$, $\tau = RC$

OT · 20 / 25

유도 · 1계 미분방정식 · 교과서 20쪽, 132쪽에서 다시 씀

치환과 변수 분리로 일반해 구하기

  1. 저항력 속 낙하, LR 회로가 모두 이 꼴이다. $y_\infty$ 는 충분히 지난 뒤의 값.

    $$\frac{dy}{dt} = \frac{y_\infty - y}{\tau}$$

  2. 목표값과의 차이 $u = y - y_\infty$ 로 바꾸면 ($du = dy$) 더 단순해진다.

    $$\frac{du}{dt} = -\frac u\tau$$

  3. 변수를 양변으로 나눈다.

    $$\frac{du}{u} = -\frac{dt}{\tau}$$

  4. $t = 0$ 에서 $u_0$ 라 하고 적분한다.

    $$\ln\frac{u}{u_0} = -\frac t\tau\ \Rightarrow\ u = u_0e^{-t/\tau}$$

  5. 원래 변수로 돌린다. 시간 $\tau$ 가 지날 때마다 남은 차이가 $1/e \approx 37\,\%$ 로 준다.

    $$y(t) = y_\infty + \big(y_0 - y_\infty\big)e^{-t/\tau}$$

  6. 예: LR 회로 ($\mathcal E = 12$ V, $R = 10\ \Omega$, $L = 0.50$ H). $y_\infty = 1.2$ A, $\tau = L/R = 0.050$ s, $y_0 = 0$.

    $$I(0.10\ \text{s}) = 1.2\big(1 - e^{-2}\big) = 1.04\ \text{A}$$

미분방정식 · 2

2계 선형: 진동

$$\frac{d^2x}{dt^2} + 2\gamma\frac{dx}{dt} + \omega_0^2x = 0$$

$x = e^{\lambda t}$ 를 넣으면 보조방정식 $\lambda^2 + 2\gamma\lambda + \omega_0^2 = 0$ 이 나옵니다.

$$\lambda = -\gamma\pm\sqrt{\gamma^2-\omega_0^2}$$
경우해
$\gamma=0$ (단진동)$x = A\cos(\omega_0t+\phi)$

유도 · 2계 미분방정식

보조방정식과 오일러 공식으로 감쇠 진동 풀기

  1. $x = e^{\lambda t}$ 를 넣으면 모든 항에 $e^{\lambda t}$ 가 붙어 나온다.

    $$\big(\lambda^2 + 2\gamma\lambda + \omega_0^2\big)e^{\lambda t} = 0$$

  2. $e^{\lambda t}\ne0$ 이므로 괄호가 0. 근의 공식.

    $$\lambda = -\gamma\pm\sqrt{\gamma^2 - \omega_0^2}$$

  3. $\gamma \lt \omega_0$ 이면 근호 안이 음수라 근이 복소수다.

    $$\lambda = -\gamma\pm i\omega_d,\qquad \omega_d = \sqrt{\omega_0^2 - \gamma^2}$$

  4. 오일러 공식 $e^{i\theta} = \cos\theta + i\sin\theta$ 로 펼친다.

    $$e^{\lambda t} = e^{-\gamma t}\big(\cos\omega_dt \pm i\sin\omega_dt\big)$$

  5. 두 해를 더하고 빼서 실수 해 두 개를 만든 뒤 합친다.

    $$x = e^{-\gamma t}\big(C_1\cos\omega_dt + C_2\sin\omega_dt\big) = Ae^{-\gamma t}\cos(\omega_dt + \phi)$$

  6. 예: $m = 1.0$ kg, $k = 16$ N/m, 저항 계수 $b = 0.40$ kg/s ($2\gamma = b/m$).

    $$\gamma = 0.20\ \text{s}^{-1},\quad \omega_0 = 4.0\ \text{s}^{-1},\quad \omega_d = 3.995\ \text{s}^{-1},\quad 1/\gamma = 5.0\ \text{s}$$

$\gamma = 0$ 이면 $\omega_d = \omega_0$ 인 단진동으로 돌아갑니다. 진폭이 $1/e$ 로 주는 데 5.0 s, 그동안 약 3번 진동합니다.

심화 · 교육과정 범위 밖 읽을거리

발산, 회전, 라플라시안

$$\nabla\cdot\vec A = \frac{\partial A_x}{\partial x}+\frac{\partial A_y}{\partial y}+\frac{\partial A_z}{\partial z},\qquad \nabla\times\vec A = \begin{vmatrix}\hat x&\hat y&\hat z\\ \partial_x&\partial_y&\partial_z\\ A_x&A_y&A_z\end{vmatrix}$$
$$\nabla^2V = \nabla\cdot\nabla V = \frac{\partial^2V}{\partial x^2}+\frac{\partial^2V}{\partial y^2}+\frac{\partial^2V}{\partial z^2}$$

구 대칭이면 $\nabla^2V = \dfrac{1}{r^2}\dfrac{\partial}{\partial r}\Big(r^2\dfrac{\partial V}{\partial r}\Big)$ 입니다.

헷갈리기 쉬운 점

$\nabla^2V$ 는 $\partial^2V/\partial r^2$ 와 다릅니다.

점전하 $V = \dfrac{q}{4\pi\varepsilon_0r}$ 에서 $\dfrac{\partial^2V}{\partial r^2} = \dfrac{2q}{4\pi\varepsilon_0r^3}\ne0$ 이지만, $\nabla^2V = 0$ 입니다. 이 결과는 $r\ne0$ 에서만 성립하고, 원점에서는 $\nabla^2V = -\rho/\varepsilon_0$ 입니다.

기존 OT p11~12는 ∂²V/∂r²와 ∇²V를 같은 것으로 썼고, 직교좌표 계산의 괄호 부호도 반대였습니다: ∂²(1/r)/∂x_i² = 3x_i²/r⁵ − 1/r³. 2022 전자기학은 적분형 법칙이 중심이라 이 슬라이드는 선택으로 두세요.
